# Point Quality Criteria

Shared criteria for evaluating Points. Used by both Popper and Deutsch critics.

**IMPORTANT:** All 5 criteria are equally weighted. User Voice is not optional — a technically perfect point that doesn't sound like the user is a failure.

---

## 1. Falsifiable (0-100)

**Definition:** A claim that can be proven wrong through observation or experiment.

**What to check:**
- Can you describe an observation that would disprove this?
- Does it make a specific enough prediction to be tested?
- Are the terms operationalized (measurable, observable)?
- Would believers and skeptics agree on what counts as refutation?

**Scoring guide:**
| Score | Description |
|-------|-------------|
| 0-20 | Unfalsifiable — no possible observation could prove it wrong |
| 21-40 | Weakly falsifiable — too vague to test in practice |
| 41-60 | Moderately falsifiable — testable but requires clarification |
| 61-80 | Falsifiable — clear what would prove it wrong |
| 81-100 | Strongly falsifiable — precise prediction, clear test |

---

## 2. Counterfactual (0-100)

**Definition:** A claim that asserts something that could be otherwise — not a tautology, not necessarily true.

**What to check:**
- Is there a possible world where this claim is false?
- Does it make a substantive assertion about reality?
- Could a reasonable person disagree?

**Scoring guide:**
| Score | Description |
|-------|-------------|
| 0-20 | Tautological — true by definition |
| 21-40 | Near-tautological — barely says anything |
| 41-60 | Weak — makes a claim but it's obvious |
| 61-80 | Counterfactual — non-obvious, could be otherwise |
| 81-100 | Strongly counterfactual — bold, high information content |

---

## 3. Hard-to-Vary (0-100)

**Definition:** A claim where every component is essential — you cannot change details without destroying the explanation.

**What to check:**
- Can you swap out key terms without changing meaning?
- Does every word earn its place?
- Is it specific or generic?

**Scoring guide:**
| Score | Description |
|-------|-------------|
| 0-20 | Highly variable — most terms could be swapped |
| 21-40 | Variable — several components interchangeable |
| 41-60 | Moderate — some specificity, but key terms generic |
| 61-80 | Hard to vary — most components essential |
| 81-100 | Very hard to vary — every word is load-bearing |

---

## 4. Antifragile (0-100)

**Definition:** A claim that gets stronger when challenged — criticism improves rather than destroys it.

**What to check:**
- Does the claim have built-in responses to obvious objections?
- Does it explain WHY, not just WHAT?
- Can it absorb edge cases without special pleading?

**Scoring guide:**
| Score | Description |
|-------|-------------|
| 0-20 | Fragile — any counterexample destroys it |
| 21-40 | Weak — survives some criticism but requires ad-hoc defenses |
| 41-60 | Neutral — withstands criticism but doesn't get stronger |
| 61-80 | Robust — handles objections well |
| 81-100 | Antifragile — criticism strengthens the claim |

---

## 5. User Voice (0-100) ⭐ NEW

**Definition:** Does the point sound like the user? Does it use their concepts, language, and framing?

**What to check:**
- Does it use concepts the user actually mentioned?
- Would the user recognize their own thinking in this?
- Is it free of jargon the user never used?
- Is it simple and readable?

**Scoring guide:**
| Score | Description |
|-------|-------------|
| 0-20 | Completely drifted — jargon user never used, unrecognizable |
| 21-40 | Mostly drifted — technical language dominates |
| 41-60 | Mixed — some user language, some introduced jargon |
| 61-80 | Mostly user voice — recognizable, minor additions |
| 81-100 | Pure user voice — uses their concepts, their words, their framing |

**Examples from "sender-receiver gaps" story:**

**BAD (20/100):** "Processing fluency and meaning fidelity are causally independent"
- User never said "processing fluency" or "meaning fidelity"
- Academic jargon that drifted from user's language

**GOOD (90/100):** "People claim 10/10 understanding but fail when asked to explain back — the gap between confidence and comprehension is invisible without verification"
- Uses user's concepts: "10/10", "explain back", "gap", "verification"
- Simple, readable, recognizable as their thinking

---

## Combined Score

**Total = (Falsifiable + Counterfactual + Hard-to-Vary + Antifragile + User Voice) / 5**

**Target: 90+** (lowered from 99 to be realistic while preserving user voice)

A Point scoring 90+ is:
- Testable (falsifiable)
- Non-obvious (counterfactual)
- Every word matters (hard-to-vary)
- Gets stronger under criticism (antifragile)
- **Sounds like the user** (user voice)
