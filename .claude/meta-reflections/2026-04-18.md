**26. `git stash` silently consumed all staged files — root cause was wrong command choice**
When debugging a pre-commit privacy failure, `git stash && git diff HEAD | grep ...` was run. `git stash` without `--include-untracked` stashes the index (staged files), not only unstaged changes — so all 4 staged files (decisions.md + 3 plan edits) were swept into the stash. The stash message "No local changes to save" was misleading (it meant no *unstaged* changes, not that nothing was stashed). The correct command was `git diff --cached | grep ...` (reads the staged diff without touching the index). All 4 files had to be manually re-staged.
