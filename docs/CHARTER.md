# Docs Charter — separation of duties

**This is the single source of the routing tree.** Every other doc points here; none restates it. If you are about to write a fact into a strategy doc, find its home below first — one fact, one home, pointers everywhere else. (Rationale + falsifier: [decisions.md](decisions.md) 2026-07-03 [process] "Doc separation-of-duties charter".)

## Routing decision tree

For ANY piece of information, **first match wins** — it then has exactly ONE home, and every other doc points to it instead of copying it.

1. **Identifying** — a person's name, contact, or provenance? → **`.private/`** (always; overrides everything below — the only irreversible failure on a public repo).
2. **Definition of a term**? → **`definitions.md`** (glossary only — no status words, no GTM claims).
3. **Why we decided, with a falsifier + alternatives, dated**? → **`decisions.md`** (append-only log).
4. **A falsifiable bet under test** (falsifier + priority + evidence)? → **`hypotheses.md`** (living scoreboard).
5. **Durable STRUCTURAL business model** — customer, problem, UVP, revenue model, channel-as-*bet*, unfair advantage (*change = a pivot*)? → **`lean-canvas.md`**.
6. **Durable impact MECHANISM** — cascade, spread, R₀ / √N (*change = a pivot*)? → **`theory-of-change.md`**.
7. **Current TACTICAL GTM / funnel execution** — sequence, funnel math, bands, prices, per-step targets, channel *mechanics* (*change = every experiment*)? → **`goals.md`**.
8. **Auto-computed live metric**? → **`progress.md`** `<!-- AUTO -->` block (regenerated by `./scripts/progress-refresh.sh`).
9. **Deferred idea + its revisit trigger**? → **`.private`** parking-lot.

## The tie-break: structural vs tactical

Rules 5/6 (structural) and 7 (tactical) are the pair most often confused. The test:

> **Would a Tuesday experiment rewrite it? → tactical (goals.md).
> Would changing it be a pivot? → structural (lean-canvas / theory-of-change).**

The reason to keep them apart is **churn-isolation**, not epistemic rank — *everything* in the strategy docs is an unvalidated bet. Volatile tactics (funnel choreography, prices, event run-of-show) would rewrite the durable model constantly if they lived in the canvas, and a real pivot would become indistinguishable from a routine tweak. (Full reconciliation: [decisions.md](decisions.md) 2026-07-03 [process] "Reconciled the strategy-doc routing rule onto the right axis".)

**The four tension pairs this tree resolves:**

| Tension | Structural home | Tactical home |
|---|---|---|
| Channel *bet* (who delivers — e.g. coaches) vs channel *mechanics* (a specific event format) | lean-canvas.md (rule 5) | goals.md (rule 7) |
| Current *state* vs append-only *why* | — | goals.md (7) vs decisions.md (3) |
| Name-free vs named | goals.md (7, name-free) | `.private` (1, named) |
| The *bet* vs the *execution that tests it* | hypotheses.md (4) | goals.md (7) |

**Rule 3 ↔ 4 overlap (the falsifier appears in both):** the canonical, maintained falsifier lives in **hypotheses.md** (living); **decisions.md** records the dated decision and may quote the one-line falsifier but points to hypotheses for the current version.

## Recording is never blocked, only routed

Routing is **advisory**. The default is always to **record** a fact (with a falsifier + an honest `UNTESTED` label — that requirement is the churn/scope brake, so "record freely" ≠ "dump anything"). An agent may recommend *which doc*; the founder decides; nothing is withheld. If a piece is genuinely ambiguous between structural and tactical, record it where the founder wants and move on — arguing placement IS the failure mode this charter retires. See [decisions.md](decisions.md) 2026-07-03 [process] and `/slava:maintain:docs-strategy-update` Step 2 (the gate that enforces this).
