# Facilitator Checklist — Clarity Night

What you do, in order. The why lives in [clarity-practice-event.md](clarity-practice-event.md); your helper uses [volunteer-runbook.md](volunteer-runbook.md).

## Bring

- [ ] 3 phones + chargers: host panel · recording · yours
- [ ] 2 tripods · laptop + charger · power bank
- [ ] Lavalier mics, **charged**
- [ ] S/L badges + lanyards (attendees + 5) · printed table numbers

## 45 min before

- [ ] Chairs in threes, table numbers out, badges at the door
- [ ] Recorded table = the one furthest from the others
- [ ] Projector on the deck · host panel logged in · wifi password visible
- [ ] Camera and one lavalier: record 20 s, **play back, hear words**

## Doors

- [ ] Everyone wears a badge; not onboarded → event page on their phone, standing up
- [ ] Mics to the recorded table: *"Tell your table you're recording; if anyone asks, pause, no reason needed."* Never ask the room who objects.
- [ ] Recorders: screen on, phone face up, **iPhone never locked**, Android Chrome battery unrestricted, never unplug mid-round
- [ ] Start on time; latecomers join next round

## Each round

- [ ] Ring the bell → press **Next round**. Mark leavers or swap people only if needed.
- No connection: everyone moves one seat clockwise; pairs pick the statement they're furthest apart on.

## End

- [ ] Closing questions on phones, before anyone stands up
- [ ] Announce the next night (date, venue, tonight's topic vote)
- [ ] **Group photo** (ask first; anyone can step out)
- [ ] Collect mics (count) and badges; check each recorder's transcript has words
- [ ] Ask 5 people, one by one: *"Would you host a 5-minute exercise at an event you already go to?"*
- [ ] Ask members which Chiang Mai events they're going to, and if they'd be a **clarity champion** there (a friendly face for newcomers). Note name · event · contact OK.

## Next morning

- [ ] Log: the 5 (yes? event? happened?) · champions (who, where, did anyone meet them)
- [ ] Recordings uploaded · what went wrong, while fresh
