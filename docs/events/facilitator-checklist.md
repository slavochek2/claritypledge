# Facilitator Checklist — Clarity Night

The tick-list for running one evening. Reusable for every Clarity Night; not per event.

**This file is operational only.** The format, the frame, the description copy and the run-of-show
live in [clarity-practice-event.md](clarity-practice-event.md) — read that for *what* happens and
*why*. This file is *what you do, in order, on the night*.

Roles: **facilitator** = you (the host). **Volunteer** = the person helping, who works from
[volunteer-runbook.md](volunteer-runbook.md).

---

## Bring

- [ ] Both phones + chargers (one runs the host panel, one is a spare)
- [ ] Laptop + charger for the deck
- [ ] HDMI / USB-C adapter for the projector — **test the exact adapter with the exact venue**
- [ ] Lavalier mics, **charged**, with their USB-C ends
- [ ] S/L badge cards + lanyard holders, one per attendee + 5 spare
- [ ] Printed table numbers (large, one per table)
- [ ] Printed fallback sheet: blank grid for writing table assignments by hand
- [ ] Pen
- [ ] Power bank

## Before anyone arrives (target: 45 min before start)

- [ ] Tables set up, chairs in threes, **table numbers on the tables**
- [ ] Recorded table chosen — the one furthest from the others, so the mics do not pick up neighbours
- [ ] Projector working, deck open on the right slide
- [ ] Host panel open on your phone, logged in as the event host
- [ ] Video camera for the opening set up and **recording test done** (record 20 seconds, play it back)
- [ ] Lavalier test: plug one in, record 20 seconds, **play it back and hear words**
- [ ] Wifi password written somewhere visible
- [ ] Badges laid out at the entrance

## As people arrive

- [ ] Point them at the badges — everyone wears one
- [ ] Anyone who has not onboarded: send them to the event page on their phone, let them do it
      standing up. Do not hold the room for them; they join at the next round.
- [ ] Hand out the lavaliers (see *Recording* below)
- [ ] Start on time. Late arrivals join at the next round — this is stated on the opening slide.

## Recording — what you say when you hand out a mic

Hand the mics to the people sitting at the recorded table. Say this, or close to it:

> You have a mic. Before each round, tell the people at your table you're recording, and that
> you'll pause if anyone prefers. If someone asks you to pause, pause — no explanation needed, no
> discussion. Nobody has to say why.

**Do not ask the room who does not want to be recorded.** Refusal must never become a public
declaration (decisions.md 2026-09-16). The burden sits with the person holding the mic, which is
also what the Terms say.

**Phone settings for recorders — this matters, capture fails silently otherwise:**

- [ ] **Screen stays on, phone face up on the table. Not in a pocket.**
- [ ] **iPhone: do not press the power button.** iOS Safari mutes the microphone the moment the
      screen locks or the tab goes to the background. The recorder keeps running and writes
      *silence* — you find out at the end, not at the time.
- [ ] **Android: set Chrome to unrestricted battery** before the event (Settings → Apps → Chrome →
      Battery → Unrestricted; on Samsung also remove it from Sleeping Apps). OEM battery killers
      end the recording mid-round.
- [ ] Prefer handing mics to **Android** phones where you have the choice, and set those phones up
      yourself rather than explaining it.
- [ ] Do not unplug the mic mid-round — the audio track **ends** and does not fall back to the
      built-in mic.

## During each round

Two actions, that is all:

1. [ ] **Ring the bell.**
2. [ ] **Press "Next round"** on the host panel.

Optional, only when something is obviously wrong:

- Mark someone as **left** if they have gone home
- Swap two people between tables by hand (people who already spoke, people who would rather not sit
  together — no algorithm knows this, you do)

**You never read out who sits where.** The projector shows the table list; each phone shows its own
assignment. If the software is not working, write the groups on the fallback sheet and read those —
the format tolerates tables of 2, 3 or 4, so you do not have to get it exactly right.

## At the end

- [ ] Run the closing sequence (feedback → positions → topics → next event → the rest)
- [ ] Announce the next Clarity Night: date, venue, topic chosen from tonight's votes
- [ ] **Take the group photo.** This is the one that gets forgotten. Ask first; anyone who prefers
      not to be in it steps out of frame, no explanation.
- [ ] Collect the lavaliers — count them against what you handed out
- [ ] Collect leftover badges and lanyards
- [ ] Check with each recorder that their transcript actually has words in it, before they leave

## After, same evening or next morning

- [ ] Confirm the recordings uploaded
- [ ] Note anything that went wrong while it is still fresh — the next event is in a week
