# Landing Copy Options

**Created:** 2026-01-29
**Decision session:** Understanding calibration clarity + copy iteration

## Hypothesis: P110 Research-Backed (Deferred)

**Status:** Deferred until we have traffic data to A/B test
**Source:** P110 research synthesis + Axios HQ + Grammarly 2022

```
8 out of 10 believe they're understood.*
Half actually understand.*
Trillions lost.** Trust dies.

*Axios HQ
**$1.2T in US (Grammarly 2022), extrapolated globally by GDP
```

**Story arc:**
1. Overconfidence (80% believe they're understood)
2. Reality (50% actually understand)
3. Consequence (cost + trust)

**Why this might win:**
- Concrete numbers add credibility (vs. abstract "everyone/nobody")
- Research-backed (coaches need proof to sell to executives)
- Clear asymmetry gap (80% vs 50%)
- Dollar figure makes it tangible

**Why we're deferring:**
- No baseline conversion data to compare against
- Current headline isn't proven worse
- "Rigorous" comparison is speculation without data

**Test when:** We have meaningful traffic + conversion tracking in place.

## Current Production (main)

```
We all crave being understood.
Let's commit to listen.
```
Sub-headline: "Stop sacrificing truth for the sake of comfort."

**Issues:** Uses "listening" (behavior) but we measure "understanding calibration" (outcome). Vague aspiration, no measurement angle.

---

## Previous Worktree (w1 before update)

```
Everyone believes listening matters.
No one measures it.
Until now.
```

**Issues:** Still uses "listening" instead of "understanding." Better than prod (has measurement angle) but not accurate to product.

---

## Final Choice (2026-01-29)

```
Feeling misunderstood hurts you.
Misunderstanding hurts others.
No one sees both sides. Until now.
```

**Why this won:**
- Leads with universal pain (instant recognition)
- Captures both sides of the equation
- "No one sees both" is the asymmetry insight
- "We all" / inclusive framing — not accusatory
- Aligned with empathetic brand voice
- Accurate to what the product measures

## Runner-Up Options

### Agent consensus pick (#21)
```
Others have always known when you didn't get it.
You're the last to know.
Not anymore.
```
**Strengths:** Provocative, creates urgency, memorable
**Weakness:** Might feel harsh, triggers shame

### Asymmetry explanation (#5)
```
You know when you're misunderstood.
You don't know when you misunderstand.
Until now.
```
**Strengths:** Clearest explanation of the blindspot
**Weakness:** Less emotional punch

### Confrontation angle (#8/#161)
```
You're sure you understood.
They're sure you didn't.
Find out who's right.
```
**Strengths:** Creates tension, action-oriented
**Weakness:** Confrontational tone

## Selection Criteria Used

| Criterion | Weight | Description |
|-----------|--------|-------------|
| **Accuracy** | High | Reflects what we actually measure (understanding, not listening) |
| **Clarity** | High | Immediately understandable, no jargon |
| **Hook** | High | Creates curiosity, stops scrolling |
| **Asymmetry** | Medium | Captures the blindspot insight |
| **Arc** | Medium | 3 lines build to resolution |
| **Emotional** | Medium | Speaks to felt pain |
| **Differentiation** | Medium | Hints at measurement/verification |
| **Brand alignment** | Medium | Empathetic, collaborative, not shaming |

## Agent Evaluations

Two independent agents evaluated all options (2026-01-29).

**Agent A top picks:** #8, #21, #23
**Agent B top picks:** #21, #5, #22

**Consensus:** #21 (knowledge gap) scored highest across both agents.

**Final decision:** Chose pain angle (#263 variant) over agent pick because:
1. More accurate to product (shows both sides)
2. Lower risk of alienation
3. Better brand alignment
4. "We all" / "No one" creates solidarity, not shame
