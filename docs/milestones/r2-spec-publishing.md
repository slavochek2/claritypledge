# MB: Spec Publishing (Recognition Track, Month 6)

**Build:** Technical specifications, API docs, architecture write-ups

**Done when:** 1+ spec published, discussed on LW/X/HN, 2+ contributors interested

**Kill signal:** Zero engagement on specs OR no contributor interest after 2 months

## Hypothesis: Specs validate recognition + attract contributors

**What we're testing:** Do technical specs:
1. Validate recognition as "calibration infrastructure person"?
2. Attract aligned contributors who want to build?

**Why this matters:**
- Specs are reputation signals for technical audience
- Shows "building infrastructure, not just app"
- Tests if recognition translates to contributor interest
- Validates alignment between positioning and community response

**The model:**
```
Essays (awareness) → Specs (technical depth) → Contributors (scaling signal) →
  → "They're building infrastructure" positioning validated
```

**Spec topics to publish:**
- Speaker verification protocol specification
- Calibration measurement stack architecture
- API design for verification loops
- Data model for Stories/Points/Positions

**How to test:**
- Publish 1-2 technical specs by Month 6
- Share on LessWrong, HackerNews, AI research forums
- Track: spec views, technical discussions, contributor inquiries
- Success signal: specs discussed, 2+ people want to contribute

**Success criteria:**
- 1+ technical spec published
- Spec discussed on LW/HN/X (5+ technical comments)
- 2+ contributors express interest in building
- Recognition signals: "you're building calibration infrastructure"

**Failure criteria:**
- Zero engagement on specs after 2 months
- No contributor interest
- Specs viewed but not discussed (no technical depth perceived)

**Alignment with dual-track:**
- Recognition track milestone (parallel to M5 coaching scale)
- Specs validate positioning as "infrastructure, not just tool"
- If contributor interest exists → potential to scale via community
- If zero engagement → recognition track not resonating with technical audience
