# Vision Track (V-track)

## What Belongs Here

**Definition:** Far-future ideas requiring new capabilities (not just scale) — 24+ month horizon, needs tech that doesn't exist yet.

**Classification criteria:**
- Requires capabilities we don't have (ML models, transcription, advanced AI)
- 24+ month timeline (not just "need scale", but "need new tech")
- High uncertainty (depends on external tech development)
- Visionary (explores what's possible, not what's validated)

**Examples:**
- V1: Transcription + AI Analysis (real-time conversation analysis)
- V2: Mirror Agents / Digital Twins (personal AI trained on verified Stories)
- V3: Predictive Calibration (ML models predict understanding gaps)

---

## Time Horizon

**24+ months** — Vision track

V-track is **VISIONARY**. These ideas explore the long-term potential of calibrated understanding.

**Characteristics:**
- Very long timeline (2+ years, depends on tech maturity)
- High uncertainty (external dependencies: AI models, transcription quality)
- High potential impact (if it works, transforms the space)
- Very low priority today (focus on C/R/E/X first)

**Key distinction from X-track:**
- **X-track:** Requires scale (can test once we have 10K users)
- **V-track:** Requires new capabilities (can't test until tech matures)

---

## Resource Constraints

**Required capabilities:**
- ML/AI expertise (fine-tuning, alignment, calibration models)
- Transcription infrastructure (real-time, high accuracy)
- Large verified dataset (Stories + verifications to train on)
- Advanced analytics (understanding gap prediction)

**Not required:**
- Immediate validation (visionary, not testable today)
- Revenue model (exploring possibility, not monetization)
- User demand (building for future, not current need)

---

## Decision Framework

**Choose V-track if the work:**
- Requires new tech capabilities (not just more users or scale)
- Timeline is 24+ months (not testable in near term)
- Explores future possibilities (not current validation)
- Depends on external tech maturity (AI models, transcription, etc.)

**Don't choose V-track if:**
- Can test with current tech → C/R/E tracks
- Just needs scale (not new capabilities) → X-track
- Near-term validation (0-12 months) → C/R tracks
- Pure infrastructure → foundation

## Success Criteria

**Track succeeds if:**
- Transcription + AI analysis works (real-time understanding gap detection)
- Mirror agents demonstrate alignment (represent user accurately)
- Predictive models achieve ≥70% accuracy (gap prediction)

**Track fails if:**
- Tech doesn't mature (transcription quality insufficient)
- AI alignment fails (mirror agents drift from user intent)
- Privacy/trust issues (users don't want AI analyzing conversations)

**CURRENT STATUS:** V-track is **on hold**. Focus on C/R tracks first. Revisit when we have:
- 10K+ users (need scale for training data)
- Verified Stories dataset (need ground truth)
- External tech maturity (AI models improve, transcription gets better)
