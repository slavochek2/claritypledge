# C2: First Workshops (Coaching Validation)

## TL;DR

**Hypothesis:** Donation-based workshops validate tool creates value and reveal what people will pay for.

**Test:** Run 3-5 workshops, measure retention, collect testimonials.

**Success:** >30% repeat attendance, clear WTP signal, tool works without founder.

**Kill signal:** <10 workshop participants AND essays <50 readers (both tracks need traction).

## Key Pivot (2026-02-03)

**Stopped trying to sell to/through coaches.** Instead: BE the coach yourself, run events, learn what works, build case studies.

**Why:**
- Coaches don't buy much software
- Double sales problem (convince coach → convince clients)
- Being the coach = fastest learning, direct feedback

## What We're Validating

| Hypothesis | How to Test |
|------------|-------------|
| H-Biz-1: Events create value | Participants report value, come back, calibration improves |
| H-Biz-2: Tool adds value beyond facilitation | Someone else runs event with tool, still works |
| H-Biz-3: People will pay | WTP signal from participants |
| H-Biz-4: Retention exists | Users return month 2+ without invitation |

## Open Questions Answered

**OQ-1: What do people pay for?**
- Options: coaching/training, membership, team dashboard, per-decision
- Answer via workshops: observe what value people articulate

**OQ-2: What are the KPIs?**
- Repeat usage: % who do second /live within 30 days
- Calibration improvement: Do gaps shrink?
- WTP signal: % who say yes to paying

**OQ-5: Tool vs You?**
- Test: Have someone else run event with tool
- If value = you → coaching business, not SaaS
