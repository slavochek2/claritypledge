# Exploratory Track (X-track)

## What Belongs Here

**Definition:** Ideas that require scale (10K+ users) to test — network effects, social dynamics, emergent behavior.

**Classification criteria:**
- Requires large user base to validate (100s or 1000s of users)
- Tests network effects or social dynamics
- Emergence-dependent (behavior only appears at scale)
- Timeline: 12-24 months (need growth first)

**Examples:**
- X1: Asymmetric Conversion (minority persuades majority via verified understanding)
- X2: Social Dynamics (group conversation, topology mapping)
- X3: Network Effects (recursive spokescouncil, common knowledge emergence)

---

## Time Horizon

**12-24 months** — Exploratory track

X-track is **SPECULATIVE**. These ideas only become testable once we have scale.

**Characteristics:**
- Long time horizon (need to grow user base first)
- High uncertainty (emergence is hard to predict)
- High potential impact (network effects unlock new value)
- Low priority until scale achieved (focus on C/R first)

---

## Resource Constraints

**Required capabilities:**
- User base at scale (10K+ users for network effects)
- Social dynamics expertise (group facilitation, topology)
- Technical infrastructure (group chat, visualization)

**Not required:**
- Immediate revenue (exploratory, not monetization)
- Proven demand (these are bets, not validated needs)

---

## Decision Framework

**Choose X-track if the work:**
- Requires scale to test (can't validate with <100 users)
- Tests network effects or social dynamics
- Depends on emergent behavior (not individual usage)
- Timeline is 12+ months (need growth first)

**Don't choose X-track if:**
- Can test with small user base → C-track or E-track
- Near-term validation (0-6 months) → C-track or R-track
- Pure infrastructure → foundation
- Requires new capabilities (not just scale) → V-track

## Success Criteria

**Track succeeds if:**
- Asymmetric conversion demonstrated (1 persuades 3+ via verified understanding)
- Topology maps reveal actionable insights
- √N growth observed (coaches teach protocol to others)

**Track fails if:**
- User base never reaches scale (stuck at <1K users)
- Network effects don't emerge (individual usage only)
- Social dynamics don't create new value

**KILL SIGNAL:** If user base doesn't reach 1K by month 18, pause X-track work. Focus on growth (C/R tracks).
