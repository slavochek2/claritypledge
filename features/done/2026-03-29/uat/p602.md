# P602 UAT: Feed Multi-Tag Select & Version Filter

## UAT-1: Multi-Tag Selection

### UAT-1.1: Toggle multiple tags
**Given:** Feed page loads with tag cloud showing understanding, misunderstanding, motivation
**When:** Click #understanding chip, then click #motivation chip
**Then:** Both chips highlighted, URL shows `?tag=understanding,motivation`, feed shows points matching either tag
**Verify:** E2E `p602-feed-multi-tag.spec.ts`

### UAT-1.2: Deselect tag from cloud
**Given:** Two tags active (understanding + motivation)
**When:** Click #understanding chip again
**Then:** Only #motivation remains active, URL updates to `?tag=motivation`
**Verify:** E2E `p602-feed-multi-tag.spec.ts`

### UAT-1.3: Dismiss from active pills
**Given:** Active filter showing [understanding x] [motivation x] pills
**When:** Click (x) on understanding pill
**Then:** Pill removed, only motivation active, feed re-filtered
**Verify:** E2E `p602-feed-multi-tag.spec.ts`

### UAT-1.4: Clear all tags
**Given:** One tag active
**When:** Dismiss the last active tag
**Then:** No tag filter, feed shows all content, URL has no `?tag` param
**Verify:** E2E `p602-feed-multi-tag.spec.ts`

## UAT-2: Version Filter

### UAT-2.1: Toggle latest versions
**Given:** Feed page on Points tab
**When:** Click "Latest" toggle
**Then:** Toggle shows ON state, URL has `?version=latest`, duplicate st8 entries collapse to one
**Verify:** E2E `p602-feed-multi-tag.spec.ts`

### UAT-2.2: Version toggle hidden on Stories tab
**Given:** Feed page on Stories tab
**When:** Look for version toggle
**Then:** Toggle is not visible
**Verify:** E2E `p602-feed-multi-tag.spec.ts`

### UAT-2.3: Shared URL with version=latest
**Given:** User opens `/feed?tag=understanding&sort=oldest&version=latest`
**When:** Page loads
**Then:** Understanding points shown, one per st-group (latest version), oldest first, toggle is ON
**Verify:** E2E + manual count verification

## UAT-3: Combined Filters

### UAT-3.1: Full curated URL
**Given:** Open `/feed?tag=understanding&sort=oldest&version=latest`
**When:** Page loads
**Then:** Points shown in st1→st9 order, one per group, latest versions only
**Verify:** Manual — count should be 9 points (one per st1-st9)

### UAT-3.2: Multi-tag combined URL
**Given:** Open `/feed?tag=understanding,motivation&sort=oldest`
**When:** Page loads
**Then:** Understanding AND motivation points shown, oldest first
**Verify:** Manual — understanding (9) + motivation (2) = 11 points
