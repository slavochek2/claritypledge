## Phase 1: Entry (Idle)

### UAT-1: Mode toggle visible on entry
**Given** both users are on the /live entry screen
**When** the session starts
**Then** a pill toggle showing "Free mode" / "Guided mode" is visible at the bottom
**And** the selected mode has `bg-blue-500 text-white` styling
**And** both users see a single "Does [partner] understand you?" button
**And** there is NO "Listen" or "Did I get it?" button (removed per AD-7)

### UAT-9: Story selection + role assignment
**Given** both users are on the entry screen in Free mode
**When** User A selects a story they authored
**Then** only User A sees the "Does [partner] understand you?" button
**And** User B sees the story card but NOT the Speak button
**And** both see a "Speak freely" link to deselect the story

**Given** no story is selected
**When** either user taps "Does [partner] understand you?"
**Then** the tapper becomes the speaker, the other becomes the listener

---

## Phases 2-3: Sealed Bid

### UAT-2: Free mode sealed bid flow
**Given** the speaker taps "Does [partner] understand you?" in Free mode
**When** the round begins
**Then** BOTH users see a drawer slide up from the bottom simultaneously
**And** the speaker sees "How well do you believe [partner] understands your intention?"
**And** the listener sees "How well do you believe you understand [partner]'s intention?"
**And** both see a slider starting at 0, scale labels "Not at all" (left) / "Complete cognitive understanding" (right)
**And** both see a Submit button and a "Speak freely" link below (mt-8 spacing)
**And** the slider shows a number display (e.g., "0/10") that updates as the slider moves

---

## Phase 4: Waiting

### UAT-2 (continued): Sealed bid submission
**Given** the speaker has submitted their sealed bid
**When** the speaker taps Submit
**Then** the speaker sees "Waiting for [partner] to submit..." with "Your answer: N/10" below
**And** the listener does NOT see any indication that the speaker submitted
**And** no "Speak freely" link is shown during waiting (round is committed)

---

## Phase 5: Reveal

### UAT-3: Reveal + gap badge display
**Given** both users have submitted their sealed bids
**When** both bids are in
**Then** both see the Journey to Understand component with dot-bars showing sealed-bid numbers
**And** the speaker sees "[partner]'s confidence" and "Your belief" (bold) rows
**And** the listener sees "Your confidence" and "[partner]'s belief" (bold) rows
**And** a gap badge appears: blue pill "N points gap" (if gap > 1) or green "Well calibrated!" (if gap <= 1)
**And** if both sealed bids are 10: green pulsing "Both at 10"
**And** the drawer shows "Initial guesses revealed" (centered, muted)
**And** the reveal auto-transitions to paraphrase after 1.5 seconds

---

## Phase 6: Paraphrase

### UAT-4: Paraphrase prompt (listener)
**Given** the reveal phase has passed (1.5s auto-transition)
**When** the paraphrase phase begins
**Then** the listener sees "Paraphrase what you understood back to [partner]" with an "I paraphrased" button
**And** the speaker sees "Waiting for [partner] to paraphrase..." with "Listen carefully to their explanation" below
**And** the gap badge persists from the reveal phase
**And** neither user has a slider visible — only the Journey and paraphrase prompt

---

## Phase 7: Unlocked

### UAT-5: Sliders unlock after paraphrase
**Given** the listener has clicked "I paraphrased"
**When** sliders unlock
**Then** both users see their slider in the drawer (starting at their sealed-bid value, not 0)
**And** the slider is freely movable without needing to tap Submit
**And** the number display updates in real-time as the slider moves (e.g., "7/10")
**And** "Speak freely" link is visible below the slider (mt-8 spacing)
**And** NO gap badge is shown in unlocked mode

### UAT-6: Continuous slider updates visible in Journey
**Given** both users are in unlocked mode
**When** either user moves their slider
**Then** the Journey component shows a live-updating row with current slider positions
**And** the partner's number updates in the Journey (not as a separate slider on screen)
**And** committed round(s) are numbered 0, 1, 2... with dot-bars above the live row

### UAT-7: 10/10 auto-success after 2-second hold
**Given** both users are in unlocked mode
**When** both sliders reach 10
**Then** green pulsing "Both at 10" celebration text appears in the Journey area
**And** if both stay at 10 for 2 seconds, auto-transition to success screen
**And** if either slider moves away from 10 during the 2 seconds, the timer resets and celebration disappears

---

## Phase 8a: Success Screen

### UAT-7 (continued): Success screen content
**Given** both sliders held at 10 for 2 seconds
**When** the success screen appears
**Then** both users see:
  - Journey showing Round 0 (sealed bid) + final 10/10 with dot-bars
  - "Mutual understanding reached" (green, prominent)
  - Starting gap: N points (from sealed bid)
  - Final: 10/10 — Well calibrated
  - "Discuss another story" button (primary, blue)
  - "End session" button (secondary, text)
**And** NO "Accept as understood" / "Try again" buttons (guided mode pattern not used)

---

## Phase 8b: Speak Freely (Return to Entry)

### UAT-8: Speak freely returns to entry
**Given** users are in unlocked mode (or sealed-bid, or paraphrase)
**When** either user taps "Speak freely"
**Then** both return to the entry screen (Phase 1)
**And** mode pill toggle is visible again
**And** roles are reset — either person can claim speaker next
**And** story is deselected
**And** round data (if sealed bids were committed) persists in session history

## Cross-Mode Validation

### UAT-10: Guided mode still works via toggle
**Given** both users are on the entry screen
**When** "Guided mode" is selected in the pill toggle
**Then** the guided mode flow proceeds as before (structured turn-taking, 0-10 buttons, accept/retry)
**And** the entry screen shows the same single "Does [partner] understand you?" button
**And** there is NO Listen button (removed for both modes per AD-7)

## Edge Cases

### UAT-11: Disconnect during sealed bid
**Given** one user disconnects during sealed bid (Phase 3)
**When** the grace period (120s) starts
**Then** the remaining user sees ReconnectingCountdown
**And** if the disconnected user had submitted, their sealed bid remains in DB
**And** if not submitted, their partial slider position is lost (local state)
**And** on reconnect, user rejoins at correct phase (Phase 3 with slider at 0, or Phase 4 if submitted)

### UAT-12: Browser reload mid-phase
**Given** user reloads during unlocked mode (Phase 7)
**When** the page reloads
**Then** phase state re-reads from liveState (Realtime)
**And** slider resets to user's last-broadcast value (stored in liveState)
**And** Journey rebuilds from committed rounds in DB
**And** session continues without data loss (except sub-second in-flight slider drag)

### UAT-13: Mobile touch interaction
**Given** both users are on mobile phones (face-to-face use case)
**When** using the slider
**Then** slider responds to touch drag smoothly (touch-action: none)
**And** "Speak freely" link has sufficient spacing (mt-8) to avoid accidental taps
**And** interactive elements are >= 40px height
**And** drawer shadow and rounded corners render correctly
