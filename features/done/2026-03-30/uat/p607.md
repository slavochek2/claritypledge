# UAT: P607 — Visibility Inheritance on Content Creation

## Prerequisites
- Logged in as a verified user
- At least one private story and one public story exist
- At least one private point and one public point exist

---

### UAT-1: Point from private story inherits private visibility

**Given:** User is on a private story detail page
**When:** User creates a new point from that story (inline add-point form)
**Then:** The created point has `visibility: 'private'`
**Verify:** Query DB: `SELECT visibility FROM points WHERE id = '<new_point_id>'` → `'private'`

---

### UAT-2: Point from public story inherits public visibility

**Given:** User is on a public story detail page
**When:** User creates a new point from that story
**Then:** The created point has `visibility: 'public'`
**Verify:** Query DB: `SELECT visibility FROM points WHERE id = '<new_point_id>'` → `'public'`

---

### UAT-3: Story from private point inherits private visibility

**Given:** User navigates to create-story page with `?pointId=<private_point_id>`
**When:** User writes and submits a story
**Then:** The created story has `visibility: 'private'`
**Verify:** Query DB: `SELECT visibility FROM stories WHERE id = '<new_story_id>'` → `'private'`

---

### UAT-4: Story from public point inherits public visibility

**Given:** User navigates to create-story page with `?pointId=<public_point_id>`
**When:** User writes and submits a story
**Then:** The created story has `visibility: 'public'`
**Verify:** Query DB: `SELECT visibility FROM stories WHERE id = '<new_story_id>'` → `'public'`

---

### UAT-5: Standalone creation still defaults to public

**Given:** User creates a story from `/create` (no point context, no doc context)
**When:** User submits the story
**Then:** Story has `visibility: 'public'` (DB default)
**Verify:** No regression — same behavior as before

---

### UAT-6: Cross-visibility constraint still blocks

**Given:** A private point and a public story exist
**When:** Attempting to link the private point to the public story
**Then:** DB constraint blocks the link (P586 cross-visibility check)
**Verify:** Error returned, no row in `story_points`

---

### UAT-7: Private content not visible in feed

**Given:** A private story and private point exist
**When:** Visitor (unauthenticated) browses the feed
**Then:** Private stories and private points do not appear
**Verify:** Feed queries filter `.eq('visibility', 'public')` — already enforced by P586
