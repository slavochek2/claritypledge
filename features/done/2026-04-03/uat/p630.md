# UAT: P630 — Separate System Tags from User Tags

## Pre-conditions
- Migration applied to test DB (`supabase db push`)
- Feed page accessible at `/feed`

---

### UAT-1.1: Feed sorting unchanged after migration
**Given:** Feed page with st1–st9 stories and points
**When:** Navigate to `/feed`
**Then:** Stories and points appear in st-number order (st1 first, st9 last)
**Verify:** Visual inspection — feed order matches pre-migration order

### UAT-1.2: Version collapsing unchanged
**Given:** Points with v1 and v2 versions exist for same st-group
**When:** Navigate to `/feed`
**Then:** Only latest version (v2) shows for each st-group
**Verify:** Count visible points per st-group — should be 1

### UAT-1.3: Tag cloud shows only user tags
**Given:** Feed page with tag filter cloud
**When:** Navigate to `/feed`
**Then:** Tag cloud does NOT show: st1-st9, v1, v2, understanding, misunderstanding
**Verify:** Visual inspection of tag cloud

### UAT-2.1: User hashtag extraction works
**Given:** Authenticated user on story creation page
**When:** Create a story with `#leadership #teamwork` in content
**Then:** Tags `leadership` and `teamwork` appear on the story card
**Verify:** Check story detail page — TagPills show both tags

### UAT-2.2: System-pattern hashtags in user content don't become system tags
**Given:** Authenticated user on story creation page
**When:** Create a story with `#v2 #st5` in content text
**Then:** `v2` and `st5` appear as user tags on the story card BUT do NOT affect feed sorting/collapsing
**Verify:** Feed still sorts by actual system tags, not the user's #v2/#st5

### UAT-3.1: Rogue tags cleaned from prod
**Given:** Prod database after migration
**When:** Query points for motivation and deprecated tags
**Then:** Zero results — both rogue tags removed
**Verify:** `curl` query on prod REST API filtering by `motivation` and `deprecated` returns empty

### UAT-3.2: Point slug resolution works
**Given:** Point with system_tags `['st1', 'v1', 'understanding']`
**When:** Navigate to `/point/st1`
**Then:** Resolves to the correct latest-version point
**Verify:** Page loads correct point content

### UAT-3.3: Category filtering works
**Given:** Feed page with filter controls
**When:** Filter by `understanding`
**Then:** Only points with `understanding` in system_tags appear
**Verify:** All visible points have understanding category
