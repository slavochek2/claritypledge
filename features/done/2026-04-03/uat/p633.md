# UAT: P633 — Unlink Button on Story Detail Page

## Prerequisites

- Logged in as a user who has authored a story with at least one linked point

## Test Scenarios

### 1. Author sees unlink icon

- [ ] Navigate to `/story/:id` for a story you authored
- [ ] Points section is expanded (auto-expands on detail view)
- [ ] Each QuotedPoint card shows an Unlink2 icon (right-aligned, below position buttons)
- [ ] Icon is muted gray by default
- [ ] Icon turns red on hover
- [ ] Hovering shows tooltip "Unlink point from story"

### 2. Non-author does NOT see unlink icon

- [ ] Navigate to same story page while logged in as a different user
- [ ] No unlink icon visible on any QuotedPoint
- [ ] Navigate while logged out — no unlink icon visible

### 3. Confirmation dialog

- [ ] Click the unlink icon
- [ ] Dialog opens with title "Unlink point from story?"
- [ ] Dialog shows truncated point statement in italics
- [ ] Dialog body text: "The point will remain visible to others who have taken positions on it."
- [ ] Two buttons: "Cancel" (outline) and "Unlink" (destructive red)

### 4. Confirm unlink

- [ ] Click "Unlink" in dialog
- [ ] Button shows "Unlinking..." with spinner while in flight
- [ ] Point disappears from story's linked points
- [ ] Footer updates point count (e.g., "2 points" → "1 point")
- [ ] Toast shows "Point unlinked from story."
- [ ] Dialog closes

### 5. Cancel unlink

- [ ] Click unlink icon to open dialog
- [ ] Click "Cancel"
- [ ] Dialog closes
- [ ] Point remains in story

### 6. Last point

- [ ] On a story with exactly 1 linked point, unlink it
- [ ] Footer shows "0 points" after unlink
- [ ] No errors or broken UI

### 7. Visual consistency

- [ ] Unlink icon matches the style of P621's unlink on point-detail page
- [ ] Icon does not overlap with position buttons or thread lines
- [ ] Touch target is at least 40x40px
