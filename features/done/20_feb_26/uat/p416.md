# UAT Scenarios: P416 — Event Auto-Banner via Unsplash

Manual validation checklist. Run after `/dev` completes and tests pass.

---

## UAT-1: Auto-fetch on Event Creation

### UAT-1.1: Banner auto-fetched on create
**Given:** Logged-in host
**When:** Creates an event with title "Morning Hike Golden Gate Park"
**Then:** `banner_url` is set in DB and banner image appears on the event detail page
**Verify:** Supabase → events table → check `banner_url` not null; navigate to event page → see photo

### UAT-1.2: Unsplash failure is silent
**Given:** Unsplash returns no results or network is blocked
**When:** Creates an event
**Then:** No error toast; `banner_url` remains null; gradient header shows on detail page
**Verify:** DevTools → Network → block api.unsplash.com → create event → no error shown

### UAT-1.3: All-noise title still creates event
**Given:** Title is "Clarity Lab Session #1" (all stripped words)
**When:** Submits form
**Then:** Event created without banner (keyword extraction returns empty → no Unsplash call)
**Verify:** Event page shows gradient, no banner image

## UAT-2: Banner Display

### UAT-2.1: Banner on event detail page
**Given:** Event with `banner_url` set
**When:** Any user navigates to `/events/{slug}`
**Then:** Banner image renders at top of page
**Verify:** Image visible, no broken img icon

### UAT-2.2: Gradient fallback when no banner
**Given:** Event with `banner_url = null`
**When:** Any user navigates to `/events/{slug}`
**Then:** Gradient header shows, no `<img>` element with unsplash.com src
**Verify:** Inspect DOM — no unsplash img

### UAT-2.3: Banner thumbnail on event card (list view)
**Given:** Event with `banner_url` set
**When:** User visits `/events`
**Then:** Event card shows 16:9 banner image at top
**Verify:** Card image visible; correct src attribute

### UAT-2.4: No image slot on card when no banner
**Given:** Event with `banner_url = null`
**When:** User visits `/events`
**Then:** Event card shows no image section (not a broken image, just no img element)
**Verify:** Card renders title + date without an image block

## UAT-3: Host Controls (Regenerate / Remove)

### UAT-3.1: Regenerate button visible to host
**Given:** Host views their own event detail page (banner set)
**When:** Page loads
**Then:** 🔄 Regenerate button visible in bottom-right of banner, over image
**Verify:** Button has `bg-black/50` style; only visible to host

### UAT-3.2: Remove button visible to host
**Given:** Host views their own event detail page (banner set)
**When:** Page loads
**Then:** ✕ Remove button visible alongside Regenerate
**Verify:** Same styling as Regenerate button

### UAT-3.3: Regenerate fetches a different photo
**Given:** Host clicks 🔄 Regenerate
**When:** Unsplash API responds
**Then:** New image loads (randomly selected from results, not always first)
**Verify:** Refresh a few times — different photos appear

### UAT-3.4: Remove clears banner
**Given:** Host clicks ✕ Remove
**When:** Confirmed
**Then:** Image disappears; gradient fallback shows; `banner_url = null` in DB
**Verify:** DB + visual check

### UAT-3.5: Regenerate still works after Remove
**Given:** Host removed the banner (gradient showing)
**When:** Host clicks 🔄 Regenerate
**Then:** New Unsplash photo fetched and displayed
**Verify:** Image appears after clicking Regenerate on a no-banner event

### UAT-3.6: Non-host cannot see Regenerate / Remove
**Given:** User who is NOT the host views the event detail page
**When:** Page loads
**Then:** No Regenerate or Remove buttons visible
**Verify:** Inspect DOM — buttons absent; also verify as anonymous user
