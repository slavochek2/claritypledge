# UAT: P418 — Banner Search Fallback

Manual validation checklist. Run via `/verify` or manually in browser.

---

## UAT-1: Regression — happy path unchanged

**Given:** Event with a real title (e.g. "Trail Running Bangkok"), host logged in
**When:** Host clicks "New banner"
**Then:** Banner updates to an Unsplash photo
**And:** No search input appears
**Verify:** Banner image visible in page, `banner_url` updated in DB

---

## UAT-2: Failure state — search input appears

**Given:** Event with an unrecognisable title (use browser devtools to block `api.unsplash.com` or use test event with gibberish title)
**When:** Host clicks "New banner"
**Then:** Toast does NOT say "Couldn't find..." alone — an inline text input appears below the banner buttons
**Verify:** Input visible directly below "New banner" / "Remove banner" buttons

---

## UAT-3: Custom search succeeds

**Given:** Search input is visible (from UAT-2)
**When:** Host types "forest trail" and clicks Search (or presses Enter)
**Then:** Banner updates to a relevant Unsplash photo
**And:** Search input hides
**Verify:** New banner image visible, input gone, DB `banner_url` updated

---

## UAT-4: Custom search fails

**Given:** Search input is visible (from UAT-2)
**When:** Host types "xyzxyzxyz" (gibberish) and clicks Search
**Then:** Input remains visible
**And:** Inline error text appears: "No photos found — try different keywords"
**Verify:** Input still shown, error text visible next to it, banner unchanged

---

## UAT-5: Search input absent on load

**Given:** Any event page, host logged in
**When:** Page loads (no "New banner" clicked yet)
**Then:** Search input is NOT visible
**Verify:** Only "New banner" and "Remove banner" buttons shown near banner

---

## UAT-6: Non-host sees no controls

**Given:** Any event page, non-host or anonymous user
**When:** Page loads
**Then:** Neither "New banner" button nor search input visible
**Verify:** Banner shows (or gradient), no controls present
