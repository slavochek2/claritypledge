# UAT: P470 — Point card footer attribution consistency

> Manual validation checklist. Run after implementation on a real browser session.
> Prerequisite: be logged in as two users (use two browsers or incognito).

## Setup

Prepare two test users: **Alice** (profile owner) and **Bob** (viewer).
Create at least one Point on Alice's profile where Alice has taken a position.

## Points Tab — Attribute cases (profile-page-v2 + point-card-with-links)

**Setup:** Log in as Alice. Alice has a position + story on a point.
Navigate to Alice's profile → Points tab.
