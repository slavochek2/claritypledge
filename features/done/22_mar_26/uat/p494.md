# UAT: P494 — Event Grace Period

## Pre-conditions
- At least one event exists with `datetime` in the past 1-4 hours (within grace)
- At least one event exists with `datetime` > 6 hours ago (outside grace)
- At least one future event exists

---

### UAT-1: Events page — grace period keeps recent events in "upcoming"

**Given:** An event started 2 hours ago (datetime is 2 hours in the past)
**When:** User visits `/events`
**Then:** The event appears in the "Upcoming Events" section, NOT in "Past Events"
**Verify:** Visual check on events page

### UAT-2: Events page — old events appear in "past"

**Given:** An event started 6+ hours ago
**When:** User visits `/events`
**Then:** The event appears in the "Past Events" section
**Verify:** Visual check on events page

### UAT-3: Registration works during grace period

**Given:** An event started 1 hour ago (within grace period), user is not registered
**When:** User navigates to the event page and clicks "Register"
**Then:** Registration succeeds — user is added to attendee list
**Verify:** Click Register button, confirm attendee count increases

### UAT-4: Dashboard "next event" shows grace-period events

**Given:** User is registered for an event that started 2 hours ago
**When:** User visits their dashboard
**Then:** The event still appears in the "Next Event" widget
**Verify:** Visual check on dashboard

### UAT-5: "Discover events" shows grace-period events

**Given:** An event from another host started 3 hours ago, user is not registered
**When:** User visits dashboard "Discover Events" section
**Then:** The event appears as a discoverable event
**Verify:** Visual check on dashboard

### UAT-6: Future events unaffected

**Given:** An event scheduled for next week
**When:** User visits `/events`
**Then:** The event appears in "Upcoming Events" as before
**Verify:** Visual check — no regression

### UAT-7: Exact boundary — 5-hour mark

**Given:** An event started exactly 5 hours ago
**When:** User visits `/events`
**Then:** The event appears in "Past Events" (grace period = strict < 5 hours)
**Verify:** Requires time manipulation or patient waiting
