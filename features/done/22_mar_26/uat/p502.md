# UAT: P502 — Gentle Anonymous Position UX

## Prerequisites
- Anonymous (not logged in) browser session
- At least one point exists with position buttons visible

---

## UAT-1: Optimistic UI — Position Highlights Without Redirect

### UAT-1.1: Click position as anonymous user
**Given:** Anonymous user on point detail page
**When:** User clicks "Agree" button
**Then:** Button highlights (emerald/selected state), no redirect to /signup
**Verify:** Browser URL stays on /point/{id}

### UAT-1.2: CTA appears after click
**Given:** Anonymous user clicks a position button
**When:** Button highlights
**Then:** Text appears: "Sign up or log in to save your position"
**Verify:** CTA text visible below buttons, contains "Sign up" and "log in" as blue links

### UAT-1.3: Position counts unchanged
**Given:** Point shows "Agree 12"
**When:** Anonymous user clicks Agree
**Then:** Count stays at 12 (does not increment to 13)
**Verify:** Compare count before/after click

---

## UAT-2: Toggle and Deselect Behavior

### UAT-2.1: Toggle to different position
**Given:** Anonymous user has clicked "Agree"
**When:** User clicks "Disagree"
**Then:** Agree unhighlights, Disagree highlights, CTA stays visible
**Verify:** Visual button states + CTA text still present

### UAT-2.2: Deselect position
**Given:** Anonymous user has clicked "Agree"
**When:** User clicks "Agree" again
**Then:** Button unhighlights, CTA disappears
**Verify:** No selected buttons, no CTA text visible

---

## UAT-3: LocalStorage Persistence

### UAT-3.1: Position survives page reload
**Given:** Anonymous user clicked "Agree" on a point
**When:** User refreshes the page (F5)
**Then:** Agree button is still highlighted, CTA visible
**Verify:** Reload → immediate visual state without flash

### UAT-3.2: Position survives navigation
**Given:** Anonymous user clicked "Agree" on point A
**When:** User navigates to feed, then back to point A
**Then:** Agree button still highlighted
**Verify:** Navigate away and back → state preserved

---

## UAT-4: Feed Card Behavior

### UAT-4.1: Feed card CTA
**Given:** Anonymous user on /feed
**When:** User clicks position button on a feed card
**Then:** Button highlights, CTA text appears below buttons, no redirect
**Verify:** Same behavior as point detail page

---

## UAT-5: Embed Mode

### UAT-5.1: Embed CTA branding
**Given:** Anonymous user viewing embedded point (on Ghost blog test post)
**When:** User clicks position button
**Then:** CTA contains "ClarityPledge" in text
**Verify:** Visit https://blog.claritypledge.com/p/b57ec166-b393-4fc0-a537-22b9a58a34d0/ → click position in embed

### UAT-5.2: Embed links open in new tab
**Given:** CTA visible in embed
**When:** User clicks "Sign up" link
**Then:** Opens in new tab (not inside iframe)
**Verify:** Right-click → inspect link target=_blank

---

## UAT-6: Logged-In User — No Regression

### UAT-6.1: Logged-in user sees no CTA
**Given:** Logged-in user on point detail page
**When:** User clicks position button
**Then:** Position saves normally, NO "sign up" CTA appears
**Verify:** Log in first, then take position

---

## UAT-7: Batch Restore on Signup

### UAT-7.1: Anonymous positions saved after signup
**Given:** Anonymous user set positions on 2-3 different points
**When:** User clicks "Sign up" from CTA → completes signup
**Then:** All previously-set positions are saved to their account
**Verify:** After signup, navigate to each point → positions visible as logged-in user

### UAT-7.2: localStorage cleared after signup
**Given:** User completed signup with anonymous positions
**When:** User opens DevTools → Application → localStorage
**Then:** `cp-anon-positions` key is absent
**Verify:** DevTools localStorage inspection
