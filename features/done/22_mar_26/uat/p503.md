# UAT: P503 — Profile Tag Pills

## Test Execution Log

| Scenario | Result | Notes |
|----------|--------|-------|
| UAT-1.1: Tagged story shows pills on profile | ✅ | Stories tab: 6 visible tag pill links (#trapatusta, #briku, etc.), 0 raw hashtags in text — all stripped |
| UAT-1.2: Tag pills are clickable links | ✅ | Clicked #cofounders pill → navigated to /feed?tag=cofounders |
| UAT-1.3: Untagged story unchanged | ✅ | Stories without tags render normally, no empty pill containers |
| UAT-2.1: Tagged point shows pills on profile | ✅ | Points tab: "Strong build on and" with pills #cofounders #trust #communication; "slkdjflks" with #test #test2 |
| UAT-2.2: Untagged point unchanged | ✅ | Points like "nikuka", "pika chuka jaka" — no tag links present |
| UAT-3.1: Pills match feed/detail styling | ✅ | Same pill component (TagPills) used on profile as feed/detail — rounded links with consistent styling |

## Prerequisites
- User with stories containing hashtags (e.g., `#leadership #trust`)
- User with points containing hashtags
- User with stories/points without hashtags (control)

---

## UAT-1: Story tag pills on profile

### UAT-1.1: Tagged story shows pills
**Given:** A user has a public story with tags `leadership` and `trust`
**When:** Visiting their profile → Stories tab
**Then:** Story text shows without raw `#leadership #trust`; styled pill badges appear below the text
**Verify:** Visual inspection in browser

### UAT-1.2: Tag pills are clickable links
**Given:** Tag pills visible on a profile story card
**When:** Clicking a tag pill (e.g., `#leadership`)
**Then:** Navigates to `/feed?tag=leadership`
**Verify:** Click pill, confirm URL change

### UAT-1.3: Untagged story unchanged
**Given:** A user has a story without any hashtags
**When:** Visiting their profile → Stories tab
**Then:** Story text renders normally, no empty pill container
**Verify:** Visual inspection

## UAT-3: Visual consistency
