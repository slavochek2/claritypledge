# UAT: P521 — Position Buttons Progressive Disclosure

## UAT-1: Two-step Agree flow
**Given:** User views a point with position buttons (no position taken)
**When:** User taps "Agree"
**Then:** Row transforms to intensity picker showing "Somewhat | Agree | Strongly"
**When:** User taps "Strongly"
**Then:** Position saved as "strongly_agree", row returns to group view with Agree highlighted
**Verify:** Browser — tap Agree → intensity picker → Strongly → blue active state

## UAT-2: Two-step Disagree flow
**Given:** User views a point with position buttons
**When:** User taps "Disagree"
**Then:** Intensity picker shows "Somewhat | Disagree | Strongly"
**When:** User taps "Somewhat"
**Then:** Position saved as "somewhat_disagree", Disagree highlighted
**Verify:** Browser — tap Disagree → intensity picker → Somewhat → blue active state

## UAT-3: One-step Unsure
**Given:** User views a point with position buttons
**When:** User taps "Unsure"
**Then:** Position saved immediately as "unsure" — no intensity picker shown
**Verify:** Browser — tap Unsure → immediate highlight, no intermediate step

## UAT-4: Cancel via Back button
**Given:** User taps "Agree" and intensity picker is showing
**When:** User taps "← Back" above the picker
**Then:** Returns to group view (Disagree | Unsure | Agree), no position set
**Verify:** Browser — open intensity picker → tap Back → group view restored

## UAT-5: Count badge visibility
**Given:** A point where 3 users Agree, 0 Disagree, 0 Unsure
**When:** User views the position buttons
**Then:** Agree shows badge "3", Disagree shows no badge, Unsure shows no badge
**Then:** No "(0)" text visible anywhere
**Verify:** Browser — check badges vs zero-count display

## UAT-6: Change existing position
**Given:** User has "Agree" position on a point
**When:** User taps "Agree" (their active segment)
**Then:** Intensity picker opens showing current intensity highlighted
**When:** User taps "Somewhat" (different intensity)
**Then:** Position changes to "somewhat_agree"
**Verify:** Browser — tap active segment → change intensity → new selection active

## UAT-7: Switch to different group
**Given:** User has "Agree" position
**When:** User taps "Disagree"
**Then:** Intensity picker for Disagree opens
**When:** User selects intensity
**Then:** Old "Agree" removed, "Disagree" at selected intensity saved
**Verify:** Browser — switch groups → verify old deselected, new selected

## UAT-8: Responsive — narrow viewport (360px)
**Given:** User views point at 360px viewport width
**When:** Position buttons render
**Then:** Full text labels visible ("Disagree", "Unsure", "Agree") — no truncation
**Then:** No "Dis...", "Ag", or other abbreviated labels
**Verify:** DevTools responsive mode at 360px

## UAT-9: Responsive — ultra narrow (280px)
**Given:** User views point at 280px viewport width
**When:** Position buttons render
**Then:** Icon-only display (✗, ◇, ✓) — clean, no broken text
**When:** User taps an icon
**Then:** Intensity picker shows full text ("Somewhat | [Group] | Strongly") — still fits
**Verify:** DevTools responsive mode at 280px

## UAT-10: Compact mode (live session card)
**Given:** Position buttons rendered in compact+narrow mode (live story card)
**When:** Buttons render
**Then:** No count badges visible, narrower padding
**When:** User taps group → intensity picker
**Then:** No helper text below ("How strongly...") in compact mode
**Then:** "← Back" still visible
**Verify:** Navigate to /live session → check embedded position buttons

## UAT-11: Consumer compatibility regression
**Given:** Position buttons appear on: point detail, feed, story detail, profile, live session
**When:** Each page loads
**Then:** Position buttons render correctly — same API, no visual regression
**Verify:** Navigate through all consumer pages — spot check rendering
