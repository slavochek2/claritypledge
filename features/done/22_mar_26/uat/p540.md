# P540: Hyperlink Consistency — UAT Scenarios

## UAT-1: Unified Link Behavior

### UAT-1.1: Raw URL in bio (regression)
**Given:** User has bio "Visit https://example.com for more"
**When:** Viewing profile page
**Then:** "https://example.com" renders as a clickable blue link opening in new tab
**Verify:** Navigate to profile page, click link, confirm new tab opens

### UAT-1.2: Markdown link in bio (new behavior)
**Given:** User has bio "Follow [my blog](https://example.com/blog) for updates"
**When:** Viewing profile page
**Then:** "my blog" renders as a clickable blue link to https://example.com/blog
**Verify:** Navigate to profile page, confirm "my blog" is a link (not raw URL)

### UAT-1.3: Raw URL in story (new behavior)
**Given:** Story contains text "I documented this at https://example.com/analysis"
**When:** Viewing story card
**Then:** "https://example.com/analysis" renders as a clickable blue link
**Verify:** Navigate to story, confirm URL is clickable (was plain text before P540)

### UAT-1.4: Markdown link in story (migrated behavior)
**Given:** Story contains text "Read [my analysis](https://example.com/analysis)"
**When:** Viewing story card
**Then:** "my analysis" renders as a named clickable link
**Verify:** Navigate to story, confirm named link works identically to pre-P540

### UAT-1.5: Mixed content in single text
**Given:** Story contains "Check [this](https://a.com) and also https://b.com"
**When:** Viewing story card
**Then:** Two separate links: "this" → a.com, "https://b.com" → b.com
**Verify:** Both links visible and clickable

### UAT-1.6: Raw URL in point text (new behavior)
**Given:** Point text contains "See https://example.com/evidence"
**When:** Viewing point on story detail or profile
**Then:** URL renders as a clickable link
**Verify:** Navigate to point display, confirm URL is clickable

## UAT-2: Form Hints

### UAT-2.1: Story creation hint
**Given:** User is on story creation page (/create)
**When:** Page loads
**Then:** Hint below textarea reads "Paste URLs or write [click here](https://...) for named links"
**Verify:** Navigate to /create, confirm hint text visible and styled text-xs text-gray-400

### UAT-2.2: Bio editing hint
**Given:** User is on settings page (/settings)
**When:** Page loads
**Then:** Hint below bio textarea reads "Paste URLs or write [click here](https://...) for named links"
**Verify:** Navigate to /settings, confirm updated hint (was "Links auto-detected")

### UAT-2.3: Point creation hint
**Given:** User is adding a point on story detail page
**When:** Point input is visible
**Then:** Hint below input mentions link support with example syntax
**Verify:** Navigate to story detail, open point input, confirm hint visible

## UAT-3: Visual Consistency

### UAT-3.1: Color consistency
**Given:** Links exist on bio, story, and point surfaces
**When:** Viewing all three
**Then:** All links use the same blue shade (text-blue-500), no text-blue-600 anywhere
**Verify:** Compare link colors across bio, story card, and point card — visually identical

### UAT-3.2: Hover behavior
**Given:** Any link on any surface
**When:** Hovering over the link
**Then:** Underline appears on hover
**Verify:** Hover test on bio link, story link, and point link

### UAT-3.3: Links open in new tab
**Given:** Any link on any surface
**When:** Clicking the link
**Then:** Opens in a new tab (does not navigate away from ClarityPledge)
**Verify:** Click a link on each surface, confirm new tab behavior

## UAT-4: Security

### UAT-4.1: XSS prevention
**Given:** User saves bio with text "[click](javascript:alert(1))"
**When:** Viewing profile page
**Then:** Text renders as plain text, NOT as a clickable link
**Verify:** Inspect DOM — no `<a>` element with javascript: href
