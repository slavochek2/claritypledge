# UAT: P543 — Hide Zero-Position Points from Listings

## Prerequisites

- At least one point with positions (normal point)
- At least one point with zero positions (abandoned/withdrawn)
- Access to feed page, a profile with points, and live session

---

## UAT-1: Feed page excludes zero-position points

**Given:** Database has points with positions and points with zero positions
**When:** User navigates to the feed page (`/feed` or `/`)
**Then:** Only points with at least 1 position appear in the feed
**Verify:** Check that no point card shows "0" total positions. Compare against DB query:
```sql
SELECT p.id, p.statement, COUNT(pp.id) as pos_count
FROM points p
LEFT JOIN point_positions pp ON pp.point_id = p.id
GROUP BY p.id
HAVING COUNT(pp.id) = 0;
```
None of these point IDs should appear in the feed.

---

## UAT-2: Profile points tab excludes zero-position points

**Given:** A user profile has points they've positioned on, some of which now have zero total positions
**When:** Visitor views that user's profile → Points tab
**Then:** Only points with at least 1 position appear
**Verify:** Compare visible points against DB.

---

## UAT-3: Live session content picker excludes zero-position points

**Given:** User starts a live session and enters content picker
**When:** Content picker loads the user's points
**Then:** Only points with at least 1 position appear in the picker
**Verify:** Compare visible points against DB.

---

## UAT-4: Direct URL still works for zero-position points

**Given:** A point exists with zero positions
**When:** User navigates directly to `/point/{id}` for that point
**Then:** Point detail page loads successfully, shows the statement, shows "0 positions" or empty position display
**Verify:** Navigate to a known zero-position point URL — page loads, no 404.

---

## UAT-5: Story-linked point quotes still render

**Given:** A story is linked to a point that now has zero positions
**When:** User views that story on a profile page
**Then:** The point quote/card still renders within the story context
**Verify:** Find a story linked to a zero-position point, confirm it displays.

---

## UAT-6: Last position removal → point disappears from feed

**Given:** A point has exactly 1 position (from the current user)
**When:** User removes their position on that point
**Then:** On next feed load, the point no longer appears
**Verify:** Remove position → refresh feed → confirm point is gone.

---

## UAT-7: New point creation (P523 flow) is not blocked

**Given:** User creates a new standalone point (P523)
**When:** Point is created but user hasn't taken a position yet
**Then:** The point should be accessible via direct URL during the creation flow
**Verify:** Create point → immediately navigate to `/point/{new-id}` → page loads. Feed/profile exclusion is expected and correct during this transient state.
