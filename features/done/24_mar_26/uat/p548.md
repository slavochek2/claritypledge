# UAT: P548 — Embed Collapse Control

## UAT-1: Embed Default Collapsed

### UAT-1.1: Story embed collapsed by default
**Given:** A story with linked points exists
**When:** Navigate to `/story/{id}?embed=true`
**Then:** Linked points section is collapsed (chevron pointing right, content hidden)
**Verify:** Playwright navigate + check aria-expanded="false"

### UAT-1.2: Point embed collapsed by default
**Given:** A point with linked stories exists
**When:** Navigate to `/point/{id}?embed=true`
**Then:** Linked stories section is collapsed
**Verify:** Playwright navigate + check aria-expanded="false"

### UAT-1.3: Story embed expanded via param
**Given:** A story with linked points exists
**When:** Navigate to `/story/{id}?embed=true&expanded=true`
**Then:** Linked points section is expanded (chevron pointing down, content visible)
**Verify:** Playwright navigate + check aria-expanded="true"

### UAT-1.4: Point embed expanded via param
**Given:** A point with linked stories exists
**When:** Navigate to `/point/{id}?embed=true&expanded=true`
**Then:** Linked stories section is expanded
**Verify:** Playwright navigate + check aria-expanded="true"

### UAT-1.5: Manual toggle works in embed
**Given:** Embed loaded with default collapsed
**When:** User clicks the expand/collapse chevron
**Then:** Section toggles to expanded, click again collapses
**Verify:** Click toggle, check aria-expanded changes

### UAT-1.6: expanded=true without embed=true has no effect
**Given:** Normal (non-embed) story detail page
**When:** Navigate to `/story/{id}?expanded=true`
**Then:** Page renders normally as full detail page (not embed mode)
**Verify:** FocusHeader/nav visible (embeds hide it)

## UAT-2: ShareDialog Redesign

### UAT-2.1: Stacked layout — both sections visible
**Given:** User is on a point or story detail page
**When:** User clicks Share button, dialog opens
**Then:** Both "Link" and "Embed" sections visible simultaneously (no tabs)
**Verify:** Open dialog, confirm both section headers visible

### UAT-2.2: Collapsed preset is default
**Given:** ShareDialog is open on Embed section
**When:** Dialog first opens
**Then:** "Collapsed" button is selected, embed code has `?embed=true` (no `expanded`)
**Verify:** Check button styling + code content

### UAT-2.3: Expanded preset adds param
**Given:** ShareDialog is open
**When:** User clicks "Expanded" button
**Then:** Embed code updates to include `&expanded=true`
**Verify:** Click Expanded, read code block text

### UAT-2.4: Toggle back to Collapsed removes param
**Given:** ShareDialog with "Expanded" selected
**When:** User clicks "Collapsed" button
**Then:** Embed code reverts to `?embed=true` (no `expanded`)
**Verify:** Click Collapsed, read code block text

### UAT-2.5: Copy button copies correct code
**Given:** ShareDialog with "Expanded" selected
**When:** User clicks Copy button
**Then:** Clipboard contains embed code WITH `expanded=true`
**Verify:** Playwright clipboard read after copy click

### UAT-2.6: Embed section hidden for profiles
**Given:** User is on a profile page
**When:** User opens Share dialog
**Then:** Only Link section shown, no Embed section or preset row
**Verify:** Open share on profile, confirm no "Embed" text

## UAT-3: Non-Embed Behavior Unchanged

### UAT-3.1: Feed view behavior unchanged
**Given:** User views points/stories in main feed
**When:** Page loads normally (no embed param)
**Then:** Expansion behavior is same as before (collapsed in feed, expanded in detail)
**Verify:** Navigate feed, check no regression
