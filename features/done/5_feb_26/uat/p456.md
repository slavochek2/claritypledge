# UAT: P456 — Story CTA footer consistency across all surfaces

Manual checklist. Run on staging/prod after all sub-stories ship.

For each scenario: navigate to the surface, verify the stated outcome, record result.

**Test account setup:** Use a verified account that has taken positions on at least 2–3 points.
Use a separate "fresh" account (no positions, no stories) for the "no position" rows.

---

## Surfaces × States Matrix

**3 footer states per surface:**
- **State 0** — viewer has no position on this point → no footer row
- **State 1** — viewer has a position, no story linked → adaptive CTA footer
- **State 2** — viewer has a position AND at least one story linked to this point → split footer

| ID | State | Expected | Result | Notes |
|----|-------|----------|--------|-------|
| A-0 | No position | No footer row below position buttons | | |

| A-1b | Disagree, no story | Footer shows: `✗ Disagree · Why do you disagree? →` | | |
| A-1c | Unsure, no story | Footer shows: `~ Unsure · Why are you unsure? →` | | |
| A-2 | Agree + 1 story linked | Footer shows: `▶ 1 story` (left) + `+ add story →` (right) | | |
| A-3 | Agree + 2 stories linked | Footer shows: `▶ 2 stories` (left, viewer's own count) + `+ add story →` | | |

**Verify footer is inside card boundary** — nothing hangs below the card edge.
