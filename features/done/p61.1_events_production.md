## Phase 4: Auth Callback RSVP

### Task 4.1: Handle action=rsvp in AuthCallbackPage

**File:** `src/auth/AuthCallbackPage.tsx`

After profile creation, check for RSVP action:

```typescript
const searchParams = new URLSearchParams(window.location.search);
const redirectPath = searchParams.get('redirect');
const action = searchParams.get('action');

if (action === 'rsvp' && redirectPath?.startsWith('/events/')) {
  const eventSlug = redirectPath.split('/')[2];
  if (eventSlug && profile) {
    // Import real service
    const { eventsService } = await import('@/app/data/events-service');
    const event = await eventsService.getEventBySlug(eventSlug);
    if (event) {
      const success = await eventsService.rsvpToEvent(event.id, profile.id);
      if (success) {
        navigate(`/events/${eventSlug}/confirm`);
        return;
      }
    }
  }
}
```
