# UAT: P508 — Public Partner Agreement Template Page

## UAT-1: Page loads without authentication

### UAT-1.1: Anonymous access
**Given:** User is not logged in
**When:** User navigates to `/partner-template`
**Then:** Page loads with the certificate visible, no redirect to `/login`
**Verify:** Playwright navigate + check URL + check heading

### UAT-1.2: Direct link sharing
**Given:** User receives a link to `/partner-template`
**When:** User opens it in a fresh browser (no cookies)
**Then:** Page loads identically — no auth prompt, no blank state
**Verify:** Incognito browser test

---

## UAT-2: Certificate content

### UAT-2.1: Mock names displayed
**Given:** Template page is loaded
**When:** User reads the certificate
**Then:** "We, Alex and Jordan, agree to:" is visible
**Verify:** Visual inspection

### UAT-2.2: Pledge sections present
**Given:** Template page is loaded
**When:** User scrolls through the certificate
**Then:** YOUR RIGHT, OUR PROMISE, THE EXCEPTION sections are all visible with full text
**Verify:** Visual inspection

### UAT-2.3: Terms in plain language
**Given:** Template page is loaded
**When:** User reads the OUR TERMS section
**Then:** Terms are human-readable (not contract jargon): "work conversations", "at least once a month", "at least 15 minutes", "within 5 days"
**Verify:** Visual inspection

### UAT-2.4: Customizable hint
**Given:** Template page is loaded
**When:** User looks at the terms section
**Then:** A "customizable" hint is visible, indicating terms can be personalized
**Verify:** Visual inspection

### UAT-2.5: No role labels
**Given:** Template page is loaded
**When:** User looks at signature slots
**Then:** Only names shown ("Alex", "Jordan") — no "CREATOR" or "PARTNER" role labels
**Verify:** Visual inspection

## UAT-3: Call to action

### UAT-3.1: Create agreement CTA
**Given:** Template page is loaded
**When:** User clicks "Create Your Agreement →"
**Then:** Navigates to `/agreements/new/create` (may redirect to login if not authenticated)
**Verify:** Click + check URL

### UAT-3.2: Sign in link
**Given:** Template page is loaded
**When:** User clicks "Already have an account? Sign in"
**Then:** Navigates to `/login`
**Verify:** Click + check URL

## UAT-4: Responsive design

### UAT-4.1: Mobile layout
**Given:** Template page is loaded on mobile viewport (375px)
**When:** User views the page
**Then:** Certificate is readable, no horizontal scroll, CTA is tappable
**Verify:** Chrome DevTools mobile emulation

### UAT-4.2: Desktop layout
**Given:** Template page is loaded on desktop (1440px)
**When:** User views the page
**Then:** Certificate is centered with appropriate max-width, not stretched edge-to-edge
**Verify:** Visual inspection
