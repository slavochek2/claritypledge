# P127: Draft Stories from Free Live Sessions

## User Story

As a user who did a "free live" session (spoke freely without selecting a story), I want the system to create a draft story from what was discussed, so that my spoken thoughts become structured content I can review and publish.

## Context

In P124 (Event Rooms), users can enter /live and either:
1. Select an existing story/point to verify
2. "Free live" — speak freely without pre-selected content

Free live sessions should generate draft stories from the conversation, giving users a path from spontaneous discussion to structured content.

## Not Part Of

- P124 (Event Rooms) — P124 just needs the "free live" entry point
- This feature handles what happens AFTER the free live session

## Open Questions

- AI-assisted extraction or manual review?
- One draft per session or multiple if multiple topics?
- How does the draft link back to the session for context?
