# P1359: Between Clarity Nights, regulars can read the next story

## Problem

Registration onboarding (P1336) teaches one story, ST1, once. The point sequence has nine stories
(ST1→ST3→ST5→ST4→ST2→ST6→ST7→ST8→ST9). A weekly regular gets nothing new after the first night.

> Founder, 2026-09-22: *"for each event, additional event, they can optionally go and find more
> stories … over time I get more and more people who read it and then at some point … we can verify
> one-to-many where they are."*

## Solution (sketch)

After each Clarity Night, offer the next unread story in the sequence as optional reading, in the same
letter-like format as the P1336 onboarding. The host can see how far each attendee has read, so a room's
reading and understanding can later be checked one-to-many.

## Non-Goals

- Not required for attending. P1336's once-only onboarding stays the only requirement.

## When

Only after weekly regulars exist (people who attend two or more nights). Before then nobody reaches story two.
