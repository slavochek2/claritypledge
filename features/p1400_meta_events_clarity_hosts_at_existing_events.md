# P1400: Meta-events — clarity hosts attached to events that already exist (placeholder)

## Problem

> Founder, 2026-10-04: "there are events happening and on each one one can become the clarity organization leader ... it's so submit the chicken and egg" · "we recruit clarity champions from these groups ... talk to me after the event about this. That's it."

Growth today depends on the founder creating every event. Any city already has dozens of recurring events (workouts, walks, yoga, meetups) with people already going. If a person who learned the practice at a Clarity Night could attach a tiny "talk to me after about clarity" moment to an event they attend anyway, distribution would ride on existing events and existing social circles instead of new ones.

**This is a placeholder.** It records the idea and its gate. It is not approved for build.

## Appetite

Blast radius if built: public listings that name other organizers' events — reputational and legal. Decision density: many (role name, consent model, listing visibility, offers/free tier).

## Approach (when unblocked)

A volunteer registers a satellite on our platform: "I'll be at <event>, talk to me after about clarity", linking to that event's own public page. We never register anyone on another platform. The organizer's event name is shown publicly only with the organizer's consent; otherwise the satellite is visible only to the volunteer's own invitees.

## Gate — do not spec further until this passes

A **14-day hand test**, no code (in the facilitator checklist since 2026-10-04): at the next Clarity Night and the first online event, ask 5 attendees to host one 5-minute exercise at an event they already attend, with organizer permission, nothing listed. Pass = at least one volunteer runs the exercise without the founder present and someone asks for more. Zero independent starts = the scaling claim is refuted.

## Risks / Non-Goals

| Risk | Label | Note |
|---|---|---|
| Organizer sees a listing as unauthorized affiliation | MITIGATE | Consent before the event name is shown publicly |
| Personal data (volunteer, attendee contacts, event details from private group chats) | MITIGATE | No listing during the hand test; a privacy basis and notice before any public listing (Thailand PDPA; GDPR for EU visitors) |
| "Recruiting at the exit" feels pushy to other attendees | ACCEPT | Invitation only, never treating attendees as material; measured in the hand test |
| Name collides with the paid "Clarity Champions Program" | MITIGATE | Do not reuse that name; choose the role name after the hand test |

**Non-Goals**
- Do NOT sign anyone up on Meetup, Luma, Facebook or any other platform on their behalf.
- Do NOT auto-create Clarity groups for other organizers' events.
- Do NOT change the Offers/Pricing page (free tier, sponsorship) as part of this — separate decision after the hand test.
