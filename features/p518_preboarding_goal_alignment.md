# P518: Preboarding — Goal Alignment Before Live Session

## Problem

People start clarity sessions with different goals. If they disagree about the goal or it stays hidden, the session becomes ineffective. There's no moment where both people confirm: "Here's what I want to get out of this."

## Concept

A brief preboarding step before the structured session starts where both participants:
1. State their goal for this session (free text or predefined options)
2. See each other's goals
3. Acknowledge alignment (or surface the disagreement before it becomes friction)

This is a psychological safety + alignment moment. Different from the session mechanics itself.

## Open Questions

- Should this be mandatory or optional?
- Predefined goal options vs. free text?
- How does this interact with event-based sessions (where the event already sets context)?
- Is this the same as or different from the "starting the journey" framing (mutual fallibility acknowledgment)?

## User Stories

- As a participant, I want to know what my partner expects from this session, so we're aligned before we start
- As a facilitator, I want both people to acknowledge mutual fallibility upfront, so the session has psychological safety
