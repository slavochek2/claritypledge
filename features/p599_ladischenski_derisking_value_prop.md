# P599 — Update ladischenski.com De-Risking Package Value Prop

## Problem

The current de-risking package describes what Slava does *for* the co-founders. It doesn't communicate the teaching angle — that the real value is learning to do calibrated knowledge (CK) yourselves.

## Proposed Change

Update the de-risking package copy on ladischenski.com to lead with:

1. **Teach the value of calibrated knowledge** — co-founders learn why CK matters and how to use it
2. **Guide through one Partner Clarity Agreement** — Slava facilitates one real agreement as a working example
3. **Self-sufficient after that** — next time they can do it themselves

Core message: "I guide you once. Next time you can do it yourselves."

## Scope

- Update service description copy on ladischenski.com (likely the de-risking / workshop section)
- May touch pricing page or offer pages if the package is referenced there
