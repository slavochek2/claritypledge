# P615: Link existing points and stories instead of creating duplicates

## Problem Statement

Currently, adding a point to a story always creates a new point, and adding a story to a point always creates a new story. Users may already have the point or story they want to associate — forcing a new creation leads to duplicates. Users need the option to link an existing point to a story (instead of creating a new one) and link an existing story to a point (instead of creating a new one).
