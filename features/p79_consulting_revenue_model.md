# P79: Consulting & Revenue Model

## Status: Planning

## Context

Clarity Pledge is bootstrapped. Revenue needs to come from somewhere while validating H2.

**Slava's dual role:**
1. **Product builder** — Building the platform
2. **First event organizer** — Hosting events to validate H2 AND acquire consulting clients

This creates a virtuous loop: events validate the product AND generate revenue.

## Revenue Streams to Explore

### Stream 1: Consulting Services (Near-term)

| Service | Description | Target Customer |
|---------|-------------|-----------------|
| **Clarity Facilitation** | Facilitate /live sessions for teams | Teams with communication issues |
| **Clarity Workshops** | Half-day workshop on understanding gaps | Corporate L&D, team offsites |
| **Clarity Meetings** | Ongoing meeting facilitation with verification | Leadership teams, boards |

**Positioning:** "I help teams discover they're not actually disagreeing — they're misunderstanding."

### Stream 2: Event Hosting (Medium-term)

| Format | Description | Revenue Model |
|--------|-------------|---------------|
| **Online Clarity Events** | Virtual events with /live verification | Ticket sales or sponsor |
| **In-person Clarity Events** | Workshop-style events | Ticket sales |
| **Private Events** | Company-hosted events | Consulting fee |

### Stream 3: Platform (Future)

| Model | Description | When |
|-------|-------------|------|
| **Event Organizer SaaS** | Tools for organizers to run Clarity events | After H2 validated |
| **Enterprise** | Private instance for large orgs | After product-market fit |

## Slava's Event Strategy

### Goals
1. **Validate H2** — Run 30-person event with Stories/Points visible
2. **Build case studies** — Document results for consulting sales
3. **Acquire clients** — Convert attendees to consulting customers

### Event Types to Test

| Type | Size | Format | H2 Validation? |
|------|------|--------|----------------|
| Small workshop | 8-12 | In-person, 3 hours | Partial — good for mechanics |
| Online event | 20-30 | Virtual, 2 hours | Yes — if /live works online |
| Conference session | 30-50 | Conference talk + activity | Yes — if logistics work |

### Consulting Offer Integration

After events, offer:
- "Want to bring this to your team?" → Workshop booking
- "Want ongoing support?" → Clarity Meetings retainer
- "Want to host your own?" → Event organizer training (future)

## Open Questions

1. **Pricing** — What's the consulting rate? Workshop price?
2. **Positioning** — Clarity Pledge brand vs personal brand (Slava)?
3. **Capacity** — How many events/workshops per month is sustainable?
4. **Online /live** — Does verification work well virtually?

## Deliverables

1. Consulting services page (could be on claritypledge.com or separate)
2. Event landing page template
3. Post-event follow-up sequence
4. Pricing model
