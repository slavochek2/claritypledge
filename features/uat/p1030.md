# UAT: P1030 — Reverse Story and the Align Pipeline

Spec: [../p1030_reverse_story_and_align_pipeline.md](../done/2026-06-10/p1030_reverse_story_and_align_pipeline.md)

These scenarios cover work that cannot be automated in CI: prod-only writes, the two
gate-exercise pairs from Decision 8, before/after query comparisons against live data, and
grep-based content checks over skill-file prose. Automated coverage lives in:
- `e2e/integration/p1030-snapshot-stamp.spec.ts`
- `e2e/p1030-reverse-story-letter-ui.spec.ts`

**Design note (2026-08-09):** P1030 has **no migration, no column and no trigger** (Decision 2).
The marker is `letter_story_snapshots.point_config.reverseStory`, stamped by
`/align-create-letter` after the seal. Scenarios that previously checked schema state have been
rewritten against the snapshot; the calibration and ear-metric movements are **accepted, not
prevented** (Decision 3), so UAT-6 now measures the size of the movement instead of asserting
there is none.

## UAT-6: The metric movement is exactly what was accepted (Done-When)

**Given:** The founder's prod profile id, resolved at runtime (never hardcoded).
**When:** Run both queries **before** UAT-2's rating happens, then **after**:

```sql
-- (a) the listener-calibration eligibility set both surfaces share
SELECT count(*) AS n,
       avg(speaker_rating)::numeric(12,6)  AS listener_calibration_avg,
       avg(listener_rating)::numeric(12,6) AS listener_self_rating_avg
FROM story_verifications
WHERE listener_id = :founder_id
  AND speaker_rating  IS NOT NULL
  AND listener_rating IS NOT NULL;

-- (b) the counters the P940 trigger moves
SELECT ears_count, verification_session_count FROM profiles WHERE id = :founder_id;
```

**Then:** This is a **bounded-movement** check, not a no-movement check (Decision 3). Expect
exactly: `n` +1; `ears_count` +1; `verification_session_count` +1. The two averages shift by the
arithmetic the new row implies and nothing more.
**Verify:** Paste all four outputs. **Do not run vacuously** — confirm the reverse story's
`story_verifications` row exists between the two runs, otherwise the pair proves nothing. **If any
value moves by more than the amounts above, stop:** something other than this rating is writing,
and the run's number cannot be attributed.

## UAT-10: `/align-create-letter` refuse-on-silence gate — exercised failure + control (Decision 8)

letter URL is printed and opened in the browser.
