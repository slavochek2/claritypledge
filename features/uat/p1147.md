# UAT: P1147 — Credential Drift Audit

Spec: [../p1147_credential_drift_audit.md](../done/2026-06-10/p1147_credential_drift_audit.md)

**CLI-verification, not browser.** This spec touches no `src/`, `e2e/`, or `supabase/` surface —
there is nothing to click. Every scenario below is: run a command, read its output.

**Automated coverage:** `scripts/audit-credential-drift.test.sh` proves the mechanism — all 3
drift directions, the retirement candidate, the stale-consumer-list variant, the not-enumerated
exclusion, and the no-secret-value-leak invariant — against **synthetic fixtures only** (per
`.claude/rules/pii.md`, a committed test file may never carry real credential names or values).
The scenarios below are the live-data half: confirming the finished script behaves correctly
against the real registries and real local env files, which the automated suite structurally
cannot do without embedding real secrets in git history.

**Before running any scenario:** never paste raw script output into chat, a commit, or any public
surface. The audit is designed to emit fingerprints only (`first2…last2(length)`) — but until
UAT-4 below has actually confirmed that this run, on this machine, treat every terminal capture as
sensitive until verified.

---

## UAT-1: A fresh unregistered credential is caught (consumer → registry)

**Given:** a scratch directory containing one throwaway env file with a single made-up variable,
e.g. `ZZZ_UAT_SCRATCH_TEST_VAR=uat-test-only`, that is not tracked by git and does not touch
`.env.local` or any real env file.
**When:** `scripts/audit-credential-drift.sh --audit --env-dir <scratch-dir> --registry
.private/docs/accounts.md --registry .private/docs/edge-function-secrets.md`
**Then:** output contains a `CONSUMER_ONLY:ZZZ_UAT_SCRATCH_TEST_VAR` finding.
**Verify:** delete the scratch directory afterward. No tracked or `.private/` file was modified —
this is a read-only run against the real registries with a throwaway consumer surface.

---

## UAT-2: A registry row with no live consumer surfaces as a retirement candidate

**Given:** a **scratch copy** of one real registry file (`cp .private/docs/accounts.md
/tmp/uat-p1147-registry-copy.md`, never the original), with one throwaway row appended naming a
variable that appears nowhere under `src/` or `supabase/functions/` (e.g.
`ZZZ_UAT_RETIREMENT_CANDIDATE`), and a scratch env file containing that same variable (so it is
"present" but has zero live consumers).
**When:** run the audit against the scratch registry copy and scratch env dir, with
`--consumers-dir` pointed at the real `src/` + `supabase/functions/` trees.
**Then:** output contains `RETIREMENT_CANDIDATE:ZZZ_UAT_RETIREMENT_CANDIDATE`.
**Verify:** delete the scratch registry copy. The real registry was never touched.

---

## UAT-3: A not-enumerated surface is excluded from coverage, never counted as clean

**Given:** the surface named in the spec's Problem section that returns HTTP 403 to the agent's
credential by deliberate design.
**When:** run the full audit against the real registries with `--not-enumerated` naming that
surface and the 403-by-design reason.
**Then:** output contains a `NOT_ENUMERATED:<surface>:<reason>` line, and the `COVERAGE:` line's
denominator visibly excludes it — read the two numbers in `COVERAGE:<classified>/<total>` and
confirm `<total>` did not silently grow to include the unreachable surface as either
reachable-but-empty or clean.

---

## UAT-4: No secret value ever reaches the terminal

**Given:** the real `.private/docs/accounts.md`, `.private/docs/edge-function-secrets.md`, and
the three local env files named in the spec's Problem section.
**When:** run the full audit and capture stdout+stderr to a **local, gitignored scratch file**
(never commit it, never paste it).
**Then:** locally — never by pasting output anywhere — grep the captured file against each real
secret value pulled directly from the source env files. None should match. Every credential
reference in the captured output should match the `first2…last2(length)` shape instead.
**Verify:** delete the scratch capture file when done. This step is inherently manual and
machine-local: it needs the real secret values to check against, and those values must never
leave the operator's machine.
