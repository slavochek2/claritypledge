# UAT: P413 — Count any completed paraphrase exchange toward calibration

Manual validation scenarios.

**Accelerated testing:** Use DB seeding instead of 5 real live exchanges (see UAT-1.1 Setup).

## UAT-1: No-story exchanges unlock calibration

### UAT-1.1: Seeded no-story exchanges show calibration on profile
**Setup (accelerated):**
```sql
-- Insert 5 story_verifications with NULL story_id for the test listener
-- via Supabase Dashboard SQL editor or supabase-admin API
INSERT INTO story_verifications (story_id, version_id, speaker_id, listener_id, speaker_rating, listener_rating)
VALUES
  (NULL, NULL, '<speaker_id>', '<listener_id>', 7, 8),
  (NULL, NULL, '<speaker_id>', '<listener_id>', 8, 7),
  (NULL, NULL, '<speaker_id>', '<listener_id>', 6, 7),
  (NULL, NULL, '<speaker_id>', '<listener_id>', 9, 8),
  (NULL, NULL, '<speaker_id>', '<listener_id>', 7, 9);

-- Then update profile count
UPDATE profiles SET verification_session_count = 5 WHERE id = '<listener_id>';
```
**When:** Navigate to `/p/<listener_slug>`
**Then:** "Understanding Calibration" section is visible with a calibration bar
**Verify:** `mcp__claude-in-chrome__read_page` — confirm calibration section present

### UAT-1.2: Low speaker rating (< 10) still counts
**Given:** Listener has 5 no-story exchanges where speaker_rating ranges 4–7 (not perfect)
**When:** Navigate to their profile
**Then:** Calibration section still appears — low scores don't prevent calibration
**Verify:** Same as UAT-1.1

### UAT-1.3: Only 4 exchanges do NOT unlock calibration
**Given:** Listener has exactly 4 no-story exchanges (verification_session_count = 4)
**When:** Navigate to their profile
**Then:** Calibration section is NOT visible — threshold not met
**Verify:** `mcp__claude-in-chrome__read_page` — confirm "Understanding Calibration" absent

## UAT-2: Live session — no story selected

### UAT-2.1: Completing paraphrase exchange without story increments count (two-party)
**Given:** Two users in an active /live session with no story selected
**When:** Both submit their ratings in the first paraphrase round
**Then:** `story_verifications` row inserted with `story_id = NULL`; listener's `verification_session_count` increments by 1
**Verify:** Check DB via Dashboard after round completes — `story_verifications` shows NULL story_id

### UAT-2.2: After 5 no-story live exchanges calibration appears on profile
**Given:** Listener has completed 5 paraphrase rounds (no story) across one or more /live sessions
**When:** Navigate to their profile
**Then:** Calibration bar is visible
**Verify:** `mcp__claude-in-chrome__navigate` to `/p/<slug>` → confirm calibration section

## UAT-3: Existing calibration unaffected

### UAT-3.1: Story-based calibration data still computes averages correctly
**Given:** Listener has existing `story_verifications` rows with a real story_id
**When:** Navigate to their profile
**Then:** Calibration display shows same averages as before P413 (no regression)
**Verify:** Compare calibration score before and after applying P413 migration

**When:** Both participants complete a full paraphrase exchange + rating
**Then:** Round completes normally; no error toast; no console errors
**Verify:** `mcp__claude-in-chrome__read_console_messages` — no `[P413] writeVerification failed` entries
