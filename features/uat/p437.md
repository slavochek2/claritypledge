# UAT: P437 — Uncancel Event

## Setup

1. Create a future event as host
2. Cancel it (via "Cancel Event" button)
3. Verify it shows cancelled state

---

## UAT-1: Uncancel Button Visibility

### UAT-1.1: Host sees button on cancelled future event
**Given:** A future event with status = cancelled
**When:** Host views the event page
**Then:** Red cancellation banner shows with "Uncancel Event" button
**Verify:** Button visible inside the red banner section

### UAT-1.2: Non-host does not see button
**Given:** Same cancelled event
**When:** A different logged-in user views it
**Then:** Cancellation banner shows, no Uncancel button
**Verify:** Banner visible, button absent

### UAT-1.3: Anonymous user does not see button
**Given:** Same cancelled event
**When:** Logged-out visitor views it
**Then:** Cancellation banner shows, no Uncancel button
**Verify:** Button absent

### UAT-1.4: Past cancelled event — no button
**Given:** An event whose datetime has already passed, status = cancelled
**When:** Host views the event page
**Then:** Cancellation banner shows, no Uncancel button
**Verify:** Button absent (past events cannot be reinstated)

---

## UAT-2: Confirm Dialog

### UAT-2.1: Dialog opens on button click
**Given:** Host on cancelled future event
**When:** Click "Uncancel Event"
**Then:** Confirm dialog appears with title "Reinstate this event?" and mentions re-announcement email
**Verify:** Dialog visible, copy matches spec

### UAT-2.2: "Keep Cancelled" dismisses dialog, no change
**Given:** Confirm dialog open
**When:** Click "Keep Cancelled"
**Then:** Dialog closes, event still shows as cancelled, Uncancel button still present
**Verify:** No status change in DB

### UAT-2.3: Escape key dismisses dialog
**Given:** Confirm dialog open
**When:** Press Escape
**Then:** Dialog closes, event unchanged
**Verify:** Dialog gone, banner still red

---

## UAT-3: Success Flow

### UAT-3.1: Confirming reinstates event
**Given:** Confirm dialog open
**When:** Click "Yes, Uncancel"
**Then:**
- Red cancellation banner disappears
- Blue host controls bar (Edit + Cancel Event) reappears
- Toast: "Event is back on — attendees notified"
- Page no longer shows cancelled state
**Verify:** All four outcomes visible within 3 seconds

### UAT-3.2: DB reflects status = upcoming
**Given:** Uncancel confirmed
**When:** Query DB
**Then:** `events.status = 'upcoming'` for this event
**Verify:** `supabase from events select status where id = <event-id>`

### UAT-3.3: Attendees receive re-announcement email
**Given:** Attendee RSVPd before event was cancelled
**When:** Uncancel confirmed
**Then:** Attendee receives email with current event date/location
**Verify:** Check test email inbox — email subject should reference the event title

---

## UAT-4: Error Handling

### UAT-4.1: Network error shows toast (not crash)
**Given:** Host on confirm dialog
**When:** Network disconnected, click "Yes, Uncancel"
**Then:** Error toast appears, event remains cancelled, no crash
**Verify:** Page still functional after error
