# UAT: P457 — Chat Empty State Redesign

## Pre-conditions
- Logged in as any user
- Navigate to `/chat` with no URL parameters

---

## UAT-1: Empty State Visual

### UAT-1.1: AI opening bubble visible on load
**Given:** Authenticated user navigates to `/chat`
**When:** Page finishes loading
**Then:** An AI bubble is visible with text "What's your experience behind this? Brain-dump it — messy is fine."
**Verify:** `page.getByText(/brain-dump it — messy is fine/i).isVisible()`

### UAT-1.2: No blank white page
**Given:** Authenticated user navigates to `/chat`
**When:** Page finishes loading
**Then:** The thread area is NOT empty — the AI bubble is the first thing visible
**Verify:** Visually — no blank area between nav and input bar

### UAT-1.3: Input is vertically centered in empty state
**Given:** Empty chat (no messages sent yet)
**When:** Page loads on desktop (1280px+)
**Then:** The input box sits roughly in the vertical center of the page, below the AI bubble — not pinned to the bottom
**Verify:** Visual check — input is NOT at the very bottom of the screen

### UAT-1.4: Input is vertically centered on mobile
**Given:** Empty chat, viewport at 375px
**When:** Page loads
**Then:** Input is visible, not crowded, not sticky to bottom yet
**Verify:** DevTools mobile view → input box is comfortably centered

---

## UAT-2: Send Button Visibility

### UAT-2.1: Send button is blue on page load
**Given:** `/chat` loaded, no text typed
**When:** User looks at the send button
**Then:** Button has a **blue** background (not gray/muted)
**Verify:** Button color is clearly blue even with empty input

### UAT-2.2: Clicking blue send button with empty input does nothing
**Given:** Empty input, blue send button visible
**When:** User clicks the send button
**Then:** Nothing happens — no error, no empty message sent
**Verify:** Thread remains unchanged, no empty bubble appears

### UAT-2.3: Send button stays blue after typing
**Given:** User types text in input
**When:** Input has content
**Then:** Button is still blue (consistent appearance)
**Verify:** Visual check

---

## UAT-3: Placeholder Text

### UAT-3.1: Placeholder reads correctly
**Given:** Empty input field in idle/brain-dump phase
**When:** No text has been entered
**Then:** Placeholder text reads: **"Tell me so I understand you"**
**Verify:** `page.getByTestId('story-guide-input').getAttribute('placeholder')`

## UAT-4: Transition to Active Chat

### UAT-4.1: Input snaps to sticky bottom after first send
**Given:** User types first message and sends it (Enter or → button)
**When:** Message appears in thread
**Then:** Input moves to sticky bottom of page — NOT vertically centered anymore
**Verify:** Scroll thread — input stays pinned at bottom

### UAT-4.2: Thread scrolls above sticky input
**Given:** Active chat with several messages
**When:** New messages appear
**Then:** Thread auto-scrolls, input remains fixed at bottom
**Verify:** Send several messages — input never moves from bottom

### UAT-4.3: AI messages appear below the opening bubble
**Given:** First message sent
**When:** AI starts streaming a response
**Then:** Streaming indicator appears in thread above the sticky input
**Verify:** Visual — "···" streaming bubble visible above input bar

## UAT-5: Position-Triggered Flow (regression)
