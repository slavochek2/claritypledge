## UAT-1: Position Buttons Visible on All Surfaces

### UAT-1.1: Point detail page — anon user sees buttons
**Given:** User is NOT logged in
**When:** Navigate to `/point/{id}` for any published point
**Then:** Agree / Disagree / Neutral buttons are visible
**Verify:** Playwright: `page.getByText('Agree').isVisible()` → `true`
**Verify:** Manual: no blank space where buttons would be; no "login to engage" placeholder

### UAT-1.2: Profile page point cards — anon user sees buttons
**Given:** User is NOT logged in
**When:** Navigate to any user's profile page (`/{slug}`) showing the Points tab
**Then:** Position buttons are visible on each point card
**Verify:** Manual: Tab to the Points section; Agree/Disagree/Neutral buttons visible on cards

### UAT-1.3: Embedded point — anon user sees buttons
**Given:** User is NOT logged in; an external page with an embedded `<iframe src="https://claritypledge.com/point/{id}?embed=true">` is loaded
**Then:** Agree / Disagree / Neutral buttons are visible inside the iframe
**Verify:** Manual: Load a page that embeds a point; position buttons visible in the widget

## UAT-2: Anon Click → /signup Redirect with Context

### UAT-2.1: Agree click redirects to /signup
**Given:** Anon user on `/point/{id}`
**When:** Click the "Agree" button
**Then:** Browser navigates to `/signup?...`
**Verify:** `page.waitForURL(/\/signup/)` succeeds

### UAT-2.2: action=set-position in signup URL
**Given:** Anon user clicked Agree
**When:** On the /signup page
**Then:** URL contains `action=set-position`
**Verify:** `page.url().includes('action=set-position')`

### UAT-2.3: pointId in signup URL
**Given:** Anon user clicked Agree on point `{id}`
**Then:** URL contains `pointId={id}`
**Verify:** `page.url().includes('pointId=' + pointId)`

### UAT-2.4: position=agree in signup URL
**Given:** Anon user clicked "Agree"
**Then:** URL contains `position=agree`
**Verify:** `page.url().includes('position=agree')`

### UAT-2.5: redirect=/point/{id} in signup URL
**Given:** Anon user clicked Agree on `/point/{id}`
**Then:** URL contains `redirect=%2Fpoint%2F{id}` (URL-encoded)
**Verify:** `decodeURIComponent(page.url()).includes('/point/' + pointId)`

### UAT-2.6: Disagree click → position=disagree
**Given:** Anon user on `/point/{id}`, clicks "Disagree"
**Then:** Signup URL contains `position=disagree`
**Verify:** Same as UAT-2.4 but `position=disagree`

### UAT-2.7: Neutral click → position=neutral
**Given:** Anon user on `/point/{id}`, clicks "Neutral"
**Then:** Signup URL contains `position=neutral`
**Verify:** Same as UAT-2.4 but `position=neutral`

## UAT-4: New Signup → Auto-Save Position

### UAT-4.1: New user signup auto-saves position
**Given:** A new email address not in the system
**Given:** Arrive at `/signup?action=set-position&pointId={id}&position=agree&redirect=/point/{id}`
**When:** Complete the signup form → receive magic link → click it
**Then:** Position "agree" is automatically saved — user does NOT need to click Agree again
**Verify:** Navigate to `/point/{id}` after login; the Agree button shows as selected / active
**Verify:** Supabase: `select * from point_positions where point_id='{id}' and user_id='{newUserId}'` returns `agree`

### UAT-4.2: Redirect to point after new signup
**Given:** Same flow as UAT-4.1
**When:** Magic link clicked → auth callback runs
**Then:** User lands on `/point/{id}` — NOT on `/events` or dashboard
**Verify:** `page.url().includes('/point/' + pointId)`

## UAT-9: Security — ALLOWED_REDIRECT_PREFIXES

### UAT-9.1: /point/ prefix in allowlist — redirect works correctly
**Given:** Auth callback with `redirect=/point/{id}` after position save
**When:** Callback runs successfully
**Then:** User lands on `/point/{id}` — NOT on `/events` (which is the fallback when prefix is missing)
**Verify:** `page.url().includes('/point/' + pointId)` — must NOT be `/events`
**Technical check:** `grep ALLOWED_REDIRECT_PREFIXES src/auth/AuthCallbackPage.tsx | grep "/point/"` must return a match
**Why:** This is the regression test for the security gap noted in P458 §Security Review: "/point/ is missing from ALLOWED_REDIRECT_PREFIXES"
