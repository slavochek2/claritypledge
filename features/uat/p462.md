# P462: Clarity Partners Count — Header Prominence — UAT

## UAT-1: Owner with active partners — bold navy number

**Given:** Owner has 1+ active Clarity Partner agreements
**When:** Owner views their own profile
**Then:**
- ✦ icon visible before number
- Number (e.g. "6") renders large and bold navy (`text-xl font-bold text-[#002B5C]`)
- "Clarity Partners →" label renders smaller and muted (`text-sm text-muted-foreground`)
- Row links to `/p/:slug/partners`
- Min tap height ≥ 44px

**Verify:** Browser inspection or `/verify`

## UAT-2: Owner with 0 partners — muted number

**Given:** Owner has no active agreements
**When:** Owner views their own profile
**Then:**
- "✦ 0 Clarity Partners →" visible
- Number "0" renders at `text-xl text-muted-foreground` (NOT bold, NOT navy)
- Label styling unchanged from UAT-1
- Row still links to `/p/:slug/partners`

**Verify:** Browser inspection or `/verify`

## UAT-3: Non-owner, no visible agreements — nothing rendered

**Given:** Visitor has no agreements with profile owner, and owner has no public agreements
**When:** Visitor views owner's profile
**Then:** No partners count line appears in profile header

**Verify:** Visual check — line absent

## UAT-4: Visitor sees public active agreement

**Given:** Owner has a public active agreement
**When:** Any visitor (including anonymous) views owner's profile
**Then:**
- Partners count line visible with bold navy number styling
- Links to `/p/:slug/partners`

**Verify:** Incognito browser or different logged-in user

## UAT-5: Visitor with shared agreement — copy unchanged

**Given:** Visitor has an agreement with the profile owner
**When:** Visitor views owner's profile
**Then:**
- "N Clarity Partners" shown with bold navy styling (same as owner N>0)
- Number styling updated to match new prominence pattern

**Verify:** Log in as partner, visit creator's profile
