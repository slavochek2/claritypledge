# UAT: P472 — Agreements post-UAT polish

Manual checklist. Run after implementation ships to staging/feature branch.

**Feature:** Post-UAT fixes and UX improvements discovered during P466 review. Covers visual corrections to the creation certificate, data accuracy bugs, behavioral gaps, and design consistency.

**Test accounts needed:**
- Account A (Creator): a verified account with a name in their profile.
- Account B (Partner): a verified account that will receive the invitation.
- Fresh browser session (no cached session) for unauthenticated tests.

Before running UAT, verify automated tests pass:
