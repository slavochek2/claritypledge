# P481: Revoke Invitation Confirm Dialog — UAT Scenarios

## UAT-1: Dialog opens on Revoke click

**Given:** Owner is on the Connections page with a pending invitation
**When:** Owner clicks "Revoke" on a pending invitation row
**Then:** A bottom-sheet Drawer dialog opens with title "Revoke invitation?"
**Verify:** Visual check via Claude in Chrome or Playwright screenshot

## UAT-2: Dialog shows partner name

**Given:** Pending invitation for "Karl Marx"
**When:** Owner clicks "Revoke"
**Then:** Dialog description reads "Karl Marx will no longer be able to accept this invite."
**Verify:** Text content assertion in browser

## UAT-3: Keep dismisses without action

**Given:** Revoke dialog is open
**When:** Owner clicks "Keep"
**Then:** Dialog closes, invitation row remains unchanged, no API call made
**Verify:** Row still visible, network tab shows no cancel request

## UAT-4: Revoke confirms and removes row

**Given:** Revoke dialog is open
**When:** Owner clicks "Revoke" in the dialog
**Then:** Loading state appears on button, invitation is cancelled, row is removed, success toast "Invitation cancelled." appears
**Verify:** Row disappears from list, toast visible

## UAT-5: Error handling

**Given:** Revoke dialog is open, API will fail
**When:** Owner clicks "Revoke" in the dialog
**Then:** Error toast "Failed to cancel. Try again." appears, dialog closes, row remains
**Verify:** Toast message, row still present

## UAT-6: No inline Keep/Cancel (regression)

**Given:** Owner is on the Connections page with a pending invitation
**When:** Owner clicks "Revoke"
**Then:** The old inline Keep/Cancel text links do NOT appear in the row — only the dialog appears
**Verify:** Visual inspection of the row area; no button swap in the row itself

## UAT-7: Mobile bottom-sheet behavior

**Given:** Owner is on mobile (< 768px width)
**When:** Owner clicks "Revoke"
**Then:** Dialog appears as a bottom-sheet sliding up from the bottom of the screen
**Verify:** Resize browser to mobile width, visual check
