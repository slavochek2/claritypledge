# UAT: P482 — CertificatePageShell width consistency

## UAT-1: Agreement detail page width matches create/accept
**Given:** An active or pending agreement exists
**When:** User navigates to `/agreements/{id}`
**Then:** The certificate renders at the same width as on `/agreements/new`
**Verify:** Side-by-side browser comparison or Playwright MCP screenshot

## UAT-2: Create agreement page uses shared shell
**Given:** Authenticated user
**When:** User navigates to `/agreements/new`
**Then:** Certificate form renders at `max-w-3xl` (768px) width
**Verify:** Browser DevTools inspect the `[data-testid="certificate-page-shell"]` element

## UAT-3: Accept agreement page preserves parchment background
**Given:** A pending agreement with invitation link
**When:** User opens the accept link
**Then:** Page has parchment background (`bg-[#F5F3EF]`) AND certificate renders at `max-w-3xl`
**Verify:** Visual check — background color must be warm parchment, not white

## UAT-4: Non-certificate pages unchanged
**Given:** Various non-certificate pages (declined, email confirm, sign-pledge)
**When:** User navigates to each
**Then:** Width remains at their original values (no regression)
**Verify:** Visual check on `/agreements/{id}/declined` and `/agreements/confirm-email`
