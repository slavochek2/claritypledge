# P486 UAT Scenarios

## UAT-1: /create with pointId -- Context Banner

### UAT-1.1: Context banner shows point text and position
**Given:** Authenticated user has an "agree" position on a point
**When:** User navigates to `/create?pointId=X`
**Then:** ChatContextHeader displays pin icon, point text (truncated), "You agree" chip, and external link icon
**Verify:** Playwright E2E (p486-create-with-point: "ChatContextHeader shows point text and position chip")

### UAT-1.2: Loading skeleton appears during point fetch
**Given:** User navigates to `/create?pointId=X`
**When:** Point data is loading
**Then:** Skeleton pulse visible in banner area, textarea disabled, publish button disabled
**Verify:** Playwright E2E (p486-create-with-point: "Skeleton pulse visible during point loading")

### UAT-1.3: Textarea auto-focuses after point loads
**Given:** Point data finishes loading
**When:** Context banner renders
**Then:** Cursor is in the textarea, ready for typing
**Verify:** Playwright E2E (p486-create-with-point: "Focus auto-set to textarea after point loads")

## UAT-2: /create without pointId -- Plain Create (Regression)

### UAT-2.1: No context banner on plain /create
**Given:** User navigates to `/create` (no query params)
**When:** Page loads
**Then:** No context banner. Textarea auto-focused. Form behaves exactly as before P486.
**Verify:** Playwright E2E (p486-create-with-point: "No context banner when no pointId param")

### UAT-2.2: Existing functionality preserved
**Given:** User fills in story content and clicks Publish
**When:** Save completes
**Then:** Redirects to /story/:id. Toast shows "Story saved!"
**Verify:** Playwright E2E (p486-create-with-point: "Save without pointId creates story only")

---

## UAT-3: Save Flow -- Story + Point Link

### UAT-3.1: Save with pointId creates story AND links to point
**Given:** User is on `/create?pointId=X` with banner visible
**When:** User types story content and clicks Publish
**Then:** Story is created. story_points junction record links story to point. User redirected to /story/:id.
**Verify:** Playwright E2E (p486-create-with-point: "Save with pointId creates story AND links it")

### UAT-3.2: Partial failure -- linkPointToStory fails
**Given:** createStory succeeds but linkPointToStory fails
**When:** Save completes
**Then:** Toast shows "Story saved! (Point link could not be saved)". Still redirects to /story/:id.
**Verify:** Manual -- simulate by temporarily breaking story_points INSERT RLS

## UAT-4: Error Fallback

### UAT-4.1: Invalid pointId gracefully degrades
**Given:** User navigates to `/create?pointId=INVALID-UUID`
**When:** Point fetch returns null
**Then:** No banner shown. No error toast. Textarea enabled. Plain create form.
**Verify:** Playwright E2E (p486-create-with-point: "Invalid pointId degrades gracefully")

### UAT-4.2: Empty string pointId treated as no pointId
**Given:** URL is `/create?pointId=`
**When:** Page loads
**Then:** Same as plain /create. No fetch, no banner.
**Verify:** Playwright E2E (p486-create-with-point: "Empty string pointId treated as no pointId")

## UAT-5: /chat Route Redirect

### UAT-5.1: /chat bare redirects to /create
**Given:** User navigates to `/chat`
**When:** Redirect fires
**Then:** URL is `/create`. Uses `replace` (no back-button loop).
**Verify:** Playwright E2E (p486-smoke: "/chat redirects to /create")

### UAT-5.2: /chat?pointId=X preserves params
**Given:** User navigates to `/chat?from=position&pointId=X`
**When:** Redirect fires
**Then:** URL contains `/create` and `pointId=X`
**Verify:** Playwright E2E (p486-smoke: "/chat?pointId=X redirects to /create?pointId=X")

### UAT-5.3: /chat?ideaId=Y preserves ideaId
**Given:** User navigates to `/chat?ideaId=Y`
**When:** Redirect fires
**Then:** URL contains `/create` and `ideaId=Y`
**Verify:** Playwright E2E (p486-create-with-point: "/chat?ideaId=Y redirects to /create?ideaId=Y")

### UAT-5.4: /clarity-chat cascades to /create
**Given:** User navigates to `/clarity-chat`
**When:** Cascading redirect fires (/clarity-chat -> /chat -> /create)
**Then:** URL is `/create`
**Verify:** Playwright E2E (p486-smoke: "/clarity-chat cascades through /chat to /create")

## UAT-7: Accessibility

### UAT-7.1: Banner has region role and aria-label
**Given:** Context banner is loaded
**When:** Screen reader navigates by landmark
**Then:** Region "Point context" is announced
**Verify:** Playwright E2E (p486-accessibility: "Banner container has role=region")

### UAT-7.2: Loading state uses aria-busy
**Given:** Point is loading
**When:** Screen reader is active
**Then:** aria-busy="true" announced. After load, aria-busy removed.
**Verify:** Playwright E2E (p486-accessibility: "aria-busy transitions")

### UAT-7.3: Tab order is correct
**Given:** User navigates with keyboard only
**When:** Pressing Tab repeatedly from page top
**Then:** Order: Back -> Banner elements -> Textarea -> Visibility radios -> Publish
**Verify:** Playwright E2E (p486-accessibility: "Tab order flows")
