## UAT-1: AI Banner on Event Creation

### UAT-1.1: New event gets AI-generated banner automatically
**Given:** User is logged in as a host
**When:** Create a new event with title "Morning Trail Run" and location "Bukit Timah Nature Reserve"
**Then:** Event detail page shows an AI-generated banner image (not a gradient, not Unsplash stock)
**Verify:** Banner image URL contains `event-banners` (Supabase Storage), not `unsplash.com`
**Verify:** Banner loads within 15 seconds of event creation

### UAT-1.2: Banner is contextually relevant to event title
**Given:** Event created with title "Morning Trail Run"
**When:** Banner is generated
**Then:** Image visually relates to trail running / outdoor activity
**Verify:** Manual visual inspection — image should evoke running, trails, nature

### UAT-1.3: Banner is contextually relevant to event location
**Given:** Event created with location "Bukit Timah Nature Reserve"
**When:** Banner is generated
**Then:** Image may include tropical/jungle elements (location-aware generation)
**Verify:** Manual visual inspection — compare with a generic "trail run" without location context

---

## UAT-2: Regenerate Banner

### UAT-2.1: Host clicks "New banner" → new AI image appears
**Given:** Event exists with an AI-generated banner
**When:** Host clicks "New banner" button
**Then:** A new AI-generated image replaces the previous one
**Verify:** Image URL changes (different filename in Storage)

### UAT-2.2: Regenerated image is different from original
**Given:** Same as UAT-2.1
**When:** New banner loads
**Then:** The new image is visually different from the previous one
**Verify:** Manual visual comparison — not the same image

### UAT-2.3: Custom keywords guide generation
**Given:** Host on event detail page
**When:** Type "sunset ocean waves" in the banner search input and press Enter
**Then:** Generated image reflects sunset/ocean theme rather than the event title alone
**Verify:** Manual visual inspection — image should show sunset/ocean elements

---

## UAT-3: Remove Banner

### UAT-3.1: Host removes banner → gradient fallback shows
**Given:** Event has an AI-generated banner
**When:** Host clicks "Remove banner"
**Then:** Banner image disappears, gradient background shows
**Verify:** No `<img>` in the banner area; CSS gradient visible

### UAT-3.2: After remove, regeneration still works
**Given:** Banner was removed (gradient showing)
**When:** Host clicks "New banner"
**Then:** A new AI-generated banner appears
**Verify:** Image URL is a Supabase Storage URL

---

## UAT-4: Fallback Chain

### UAT-4.1: AI generation fails → Unsplash fallback
**Given:** Gemini API is unavailable (test by temporarily removing GEMINI_API_KEY from edge function secrets)
**When:** Host clicks "New banner"
**Then:** An Unsplash stock photo appears instead
**Verify:** Banner URL contains `unsplash.com` (fallback path)

### UAT-4.2: Both AI and Unsplash fail → gradient fallback
**Given:** Both Gemini API and Unsplash API are unavailable
**When:** Host clicks "New banner"
**Then:** No banner image appears; gradient remains
**Verify:** No error crash; page stays functional

---

## UAT-5: Persistence and Display

### UAT-5.1: Banner URL persists across page reloads
**Given:** Event has an AI-generated banner
**When:** Reload the event detail page (F5)
**Then:** Same banner image appears
**Verify:** Image URL unchanged after reload

### UAT-5.2: Banner visible on event card in list view
**Given:** Event has an AI-generated banner
**When:** Navigate to `/events` list page
**Then:** Event card shows the banner as a thumbnail
**Verify:** Event card contains an `<img>` with the Storage URL

## UAT-6: Non-Host View (No Regression)

### UAT-6.1: Non-host sees banner but no controls
**Given:** Logged in as a different user (not the host)
**When:** Navigate to the event detail page
**Then:** Banner image is visible; "New banner" and "Remove banner" buttons are NOT visible
**Verify:** Banner displays; no host control buttons in DOM

### UAT-6.2: Anonymous user sees banner but no controls
**Given:** Not logged in
**When:** Navigate to the event detail page
**Then:** Banner image is visible; no host controls
**Verify:** Same as UAT-6.1

## UAT-7: Visual Quality

### UAT-7.1: Banner aspect ratio is consistent
**Given:** Multiple events with AI-generated banners
**When:** View event detail pages
**Then:** Banner area has consistent aspect ratio (similar to current 16:9-ish layout)
**Verify:** No vertical stretching, cropping artifacts, or overflow

### UAT-7.2: No visible text or words in generated image
**Given:** AI-generated banner
**When:** Inspect the image
**Then:** Image contains no rendered text, letters, or numbers
**Verify:** Manual visual inspection — Gemini prompt includes "no text" instruction
