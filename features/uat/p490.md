# UAT: P490 — Guest Position Sync + Unsaved Hint

## Prerequisites
- Dev server running (`npm run dev`)
- One browser logged in as a verified user (host)
- One incognito/private browser window (guest)

---

### UAT-1: Guest position syncs to host view

**Given:** Host creates a /live session, guest joins via room code
**When:** Host selects a story with points, guest clicks "Disagree" on a point
**Then:**
- [ ] Host sees a position badge (Disagree) appear on the point within 1-2 seconds
- [ ] Host sees a toast notification: "[Guest name] Disagree" with the point snippet
**Verify:** Visual check in two browser windows side by side

### UAT-2: Guest position change syncs

**Given:** Guest has already set "Disagree" on a point (UAT-1 complete)
**When:** Guest changes position to "Agree"
**Then:**
- [ ] Host sees the badge update from Disagree to Agree
- [ ] Host sees a new toast notification
**Verify:** Visual check

### UAT-3: Guest sees "unsaved" hint instead of "Tell your story"

**Given:** Guest has set a position on a point during a /live session
**When:** Looking at the point card in the guest's browser
**Then:**
- [ ] Guest sees "Position shared live — sign up to save it" (or similar)
- [ ] Guest does NOT see "Tell your story → Available after the session"
**Verify:** Visual check in guest browser

### UAT-4: Authenticated partner still sees "Tell your story" CTA

**Given:** Two authenticated users in a /live session
**When:** The non-author user sets a position on a point
**Then:**
- [ ] They see the "Tell your story → Available after the session" CTA (disabled)
- [ ] They do NOT see "sign up to save" messaging
**Verify:** Visual check — requires two logged-in accounts

### UAT-5: Position sync works when Realtime drops (polling fallback)

**Given:** Host and guest in a /live session
**When:** Guest sets a position (simulate Realtime drop by checking it still works after a few seconds)
**Then:**
- [ ] Host sees the position badge appear — even if there's a brief delay (up to 1s poll interval)
**Verify:** Visual check. If Realtime is working, it appears instantly. If polling kicks in, within 1 second.

### UAT-6: No regression — host's own positions still work

**Given:** Host and guest in a /live session with a story selected
**When:** Host sets a position on a point
**Then:**
- [ ] Position buttons highlight correctly for the host
- [ ] Guest sees the host's position badge
**Verify:** Visual check
