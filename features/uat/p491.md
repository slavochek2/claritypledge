- Dev server running (`npm run dev`)
- At least one story and one point with tags exist in the database (visibility: public)
- One browser logged in as a verified user

### UAT-1: Feed page loads with Points tab as default

**Given:** Anonymous user navigates to `/feed`
**When:** Page loads
**Then:**
- [ ] "Feed" heading is visible
- [ ] Two tabs visible: "Points" and "Stories"
- [ ] Points tab is active (underlined/bold)
- [ ] Public points are listed below the tab bar
- [ ] Tag pills appear below point text on cards that have tags
**Verify:** Visual check in anonymous browser

### UAT-2: Stories tab shows public stories

**Given:** User is on `/feed` viewing Points tab
**When:** User clicks "Stories" tab
**Then:**
- [ ] Stories tab becomes active
- [ ] URL updates to `/feed?tab=stories`
- [ ] Public stories with author info are displayed
- [ ] Tag pills appear on story cards that have tags
**Verify:** Visual check — verify URL bar updates

### UAT-3: Tag pill click filters feed by tag

**Given:** User is on `/feed` and sees a tag pill (e.g., "fundraising") on a card
**When:** User clicks the tag pill
**Then:**
- [ ] URL updates to `/feed?tag=fundraising`
- [ ] Active tag filter pill appears between header and tabs showing "fundraising" with an X button
- [ ] Only content matching the "fundraising" tag is shown
- [ ] Content without the "fundraising" tag disappears
**Verify:** Visual check + verify URL bar

### UAT-4: Dismiss tag filter returns to unfiltered feed

**Given:** User is on `/feed?tag=fundraising` with active filter
**When:** User clicks the X button on the active tag filter pill
**Then:**
- [ ] URL reverts to `/feed` (or `/feed?tab=stories` if on stories tab)
- [ ] Active tag filter pill disappears
- [ ] All public content is shown again
**Verify:** Visual check

### UAT-5: Tab switching preserves tag filter

**Given:** User is on `/feed?tag=fundraising` (Points tab)
**When:** User clicks "Stories" tab
**Then:**
- [ ] URL updates to `/feed?tag=fundraising&tab=stories`
- [ ] Only stories tagged "fundraising" appear
- [ ] Active tag filter pill remains visible
**Verify:** Visual check + URL verification

### UAT-6: Shared URL works for anonymous users

**Given:** A URL `/feed?tag=fundraising` is shared
**When:** Anonymous user opens the link in a fresh incognito window
**Then:**
- [ ] Feed loads with "fundraising" filter active
- [ ] Filtered content is visible (no auth wall)
- [ ] Active tag filter pill shows "fundraising"
**Verify:** Open in incognito browser

### UAT-7: Authenticated user redirect — / to /feed

**Given:** User is logged in as a verified user
**When:** User navigates to `/`
**Then:**
- [ ] User is redirected to `/feed`
- [ ] Feed page loads normally with Points tab active
**Verify:** Check URL bar changes from `/` to `/feed`

### UAT-8: Anonymous user on / sees landing page

**Given:** User is not logged in
**When:** User navigates to `/`
**Then:**
- [ ] Landing page is shown (no redirect to `/feed`)
- [ ] ClarityPledge landing content is visible
**Verify:** Visual check in incognito browser

### UAT-9: Feed replaces History in bottom nav

**Given:** Verified user on mobile viewport
**When:** Looking at the bottom navigation bar
**Then:**
- [ ] "Feed" appears in bottom nav (where "History" used to be)
- [ ] "History" does NOT appear in bottom nav
- [ ] Tapping "Feed" navigates to `/feed`
- [ ] Feed icon highlights when on `/feed` or `/feed?tag=X`
**Verify:** Visual check on mobile or responsive view (< 1024px)

### UAT-10: History accessible from menu

**Given:** Verified user on the app
**When:** User opens the hamburger/avatar menu
**Then:**
- [ ] "History" appears at the top of the verified-user menu items
- [ ] Clicking "History" navigates to `/sessions`
**Verify:** Check both mobile hamburger menu and desktop avatar dropdown

### UAT-11: Tags in /live are display-only (non-clickable)

**Given:** Two users in a /live session with a story that has tags
**When:** Looking at story/point cards in the /live view
**Then:**
- [ ] Tag pills are visible on cards that have tags
- [ ] Tag pills have muted styling (no hover effects)
- [ ] Clicking a tag pill does nothing (no navigation)
**Verify:** Visual check in /live session

### UAT-12: Empty state — no matching tag

**Given:** User navigates to `/feed?tag=nonexistent-tag-xyz`
**When:** Page loads
**Then:**
- [ ] Message shows: "No content tagged nonexistent-tag-xyz yet"
- [ ] "Browse all content" link is visible
- [ ] Clicking "Browse all content" navigates to `/feed` (removes filter)
**Verify:** Visual check

### UAT-13: Empty state — no public content at all

**Given:** No public stories or points exist in the database
**When:** User navigates to `/feed`
**Then:**
- [ ] Message shows: "No public content yet"
- [ ] Guidance text like "Stories and points shared publicly will appear here"
- [ ] No broken layout or error
**Verify:** Visual check (may need a clean DB)

**Given:** User on a desktop browser (1024px+)
**When:** Navigating to `/feed`
**Then:**
- [ ] Content is centered with max-width container
- [ ] Tab bar is left-aligned within content column
- [ ] No bottom nav visible (existing desktop behavior)
- [ ] Tag pills show hover state (slightly darker background)
