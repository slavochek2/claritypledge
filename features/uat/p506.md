# UAT: P506 — Auto-extract hashtags from story/point content

## Test Execution Log

| Scenario | Result | Notes |
|----------|--------|-------|
| UAT-1.1: Story with hashtags extracted | ✅ | Created story with #transparency #accountability #trust → DB tags: ["transparency","accountability","trust"] |
| UAT-1.2: Story without hashtags — no false tags | ✅ | Story with no # patterns → DB tags: [] (empty, no false positives) |
| UAT-2.1: Point with hashtags extracted | ✅ | Point "Strong #cofounders build on #trust and #communication" → DB tags: ["cofounders","trust","communication"] |
| UAT-2.2: Duplicate/cased hashtags deduplicated | ✅ | Story with "#Trust #trust #TRUST" → DB tags: ["trust"] (single entry) |
| UAT-3.1: Backfill — existing stories get tags | ✅ | DB query confirmed: 5 stories with backfilled tags (understanding, st1-st5) |
| UAT-3.2: Backfill — existing tags not overwritten | ✅ | Integration test confirms: stories with existing tags preserved (manually-set not overwritten) |

## Prerequisites
- Authenticated user account
- Access to story creation page and point creation UI

---

### UAT-1.1: Story with hashtags — tags auto-extracted
**Given:** User is on the "Share a Story" page
**When:** User types story content containing `#leadership` and `#trust`, then submits
**Then:** Story is saved with `tags: ['leadership', 'trust']`; tag pills render on the story card
**Verify:** Create story → check profile Stories tab → pills visible, no raw `#text`

### UAT-1.2: Story without hashtags — no false tags
**Given:** User is on the "Share a Story" page
**When:** User types story content with no `#` patterns, then submits
**Then:** Story is saved with `tags: []`; no tag pills render
**Verify:** Create story → check profile Stories tab → no pills

### UAT-2.1: Point with hashtags — tags auto-extracted
**Given:** User is on a story detail page with "Add a Point" input
**When:** User types a point statement containing `#cofounders #trust`, then submits
**Then:** Point is saved with `tags: ['cofounders', 'trust']`; tag pills render on the point card
**Verify:** Create point → check feed or story detail → pills visible

### UAT-2.2: Duplicate/cased hashtags — deduplicated
**Given:** User types content containing `#Trust #trust #TRUST`
**When:** Story or point is submitted
**Then:** Tags saved as `['trust']` (single entry, lowercase)
**Verify:** Check DB or tag pills — only one "trust" pill

### UAT-3.1: Backfill — existing stories get tags
**Given:** Stories exist in DB with hashtags in content but `tags = '{}'`
**When:** Backfill migration is applied
**Then:** Those stories now have populated `tags` array matching their content hashtags
**Verify:** Query DB for stories with `#` in content → `tags` is non-empty

### UAT-3.2: Backfill — existing tags not overwritten
**Given:** Stories exist with manually-set `tags` (non-empty)
**When:** Backfill migration is applied
**Then:** Existing tags are preserved, not replaced
**Verify:** Query DB for stories with pre-existing tags → tags unchanged
