# UAT: P511 — Session Resilience: Grace Period, Rejoin, and Active Session Banner

## UAT-1: Page refresh does not kill session (creator)
**Given:** Creator is in an active /live session with a partner
**When:** Creator refreshes the page (F5 / Cmd+R)
**Then:** Page reloads, session is restored automatically from sessionStorage, creator is back in the live view
**Then:** Partner does not see "Partner left" — may see brief "Reconnecting..." that resolves in seconds
**Verify:** Browser — refresh during session → session continues. Check DB: `live_state.sessionEnded` is NOT true.

## UAT-2: Pull-to-refresh on mobile does not kill session
**Given:** Creator or joiner is in an active /live session on mobile
**When:** User accidentally triggers pull-to-refresh (scroll up from top)
**Then:** Page reloads, session is restored
**Then:** Partner sees brief reconnecting indicator, then session resumes
**Verify:** Mobile Safari/Chrome — pull down → session survives. Partner does not see permanent "Partner left."

## UAT-3: Navigate away does not kill session
**Given:** User is in an active /live session
**When:** User clicks any navigation link (Events, Profile, Feed, logo)
**Then:** Navigation happens immediately — NO dialog, NO confirmation prompt
**Then:** Session stays alive in DB
**Then:** Active session banner appears on the destination page
**Verify:** Browser — click Events during session → navigates to /events immediately. No "End session?" dialog. Banner visible.

## UAT-4: Active session banner appears on all non-/live pages
**Given:** User has an active session and navigates to any page (events, profile, feed, home)
**When:** Page loads
**Then:** Blue banner appears below the navigation: "In session with [Partner Name]"
**Then:** Banner has "Rejoin Session" button (primary blue) and "End Session" link (destructive text)
**Then:** Banner pushes content down (not overlay)
**Verify:** Navigate to /events, /profile, /feed — banner visible on each. Not visible on /live itself.

## UAT-5: Banner "Rejoin Session" returns to session
**Given:** Active session banner is visible on /events
**When:** User taps "Rejoin Session"
**Then:** Navigates to /live, session reconnects, live view restored
**Verify:** Tap Rejoin → back in session on /live.

## UAT-6: Banner "End Session" kills session immediately
**Given:** Active session banner is visible on /events
**When:** User taps "End Session"
**Then:** Session ends immediately in DB
**Then:** Banner disappears
**Then:** User stays on /events (does not redirect)
**Then:** Partner sees session-ended view
**Verify:** Tap End Session on banner → banner gone, stay on current page. Check DB: session ended.

## UAT-7: Remaining partner sees "Reconnecting..." with countdown
**Given:** Two users in an active session
**When:** One user navigates away or refreshes (heartbeat stops for 10+ seconds)
**Then:** Remaining partner sees "Waiting for [Name] to return... M:SS remaining"
**Then:** Reassurance text: "They may be refreshing or switching apps."
**Then:** Session content remains visible and interactive
**Then:** Countdown starts from grace period remaining (2 min minus time since last heartbeat)
**Verify:** Partner A leaves → Partner B sees countdown. B can still review their content.

## UAT-8: Grace period expiry ends session for remaining partner
**Given:** Partner is seeing "Reconnecting..." countdown
**When:** Countdown reaches 0:00
**Then:** Text changes to "Session timed out. Your partner may have lost connection."
**Then:** After 5 seconds, transitions to session-ended/summary view
**Then:** "View Session Summary" link available immediately for early skip
**Verify:** Wait for countdown to expire → timeout message → summary view.

## UAT-9: Joiner can rejoin via /live landing
**Given:** Joiner was in a session, navigated away or closed tab
**When:** Joiner opens /live within 2 minutes
**Then:** /live shows rejoin prompt: "Your session is still running" with session code
**Then:** "Rejoin Session" button (primary, large)
**Then:** One tap → rejoins session
**Verify:** Joiner leaves → returns to /live → sees rejoin prompt → taps Rejoin → back in session.

## UAT-10: Creator can rejoin via sessionStorage restoration
**Given:** Creator refreshes /live page
**When:** Page reloads
**Then:** Session restored from sessionStorage automatically — no rejoin prompt needed
**Then:** Creator is back in live view seamlessly
**Verify:** Creator refreshes → page reloads → session continues without manual rejoin step.

## UAT-11: Network drop does not show "Partner left" during grace period
**Given:** Two users in session, one experiences brief network drop (< 2 min)
**When:** Network returns
**Then:** Session resumes without "Partner left" being shown permanently
**Then:** At most, remaining partner saw "Reconnecting..." which resolved
**Verify:** Simulate offline/online toggle → session recovers. No permanent "Partner left."

## UAT-12: "End Session" button is immediate (no grace period)
**Given:** User is in /live session
**When:** User clicks "End Session" button in session header
**Then:** Session ends immediately — both partners see session-ended view
**Then:** No countdown, no reconnecting state
**Then:** localStorage and sessionStorage cleared
**Verify:** Click End Session → instant end for both. DB: sessionEnded = true immediately.

## UAT-13: P410 navigation dialog is completely removed
**Given:** User is in an active /live session
**When:** User clicks logo, Events link, Profile link, or any bottom nav item
**Then:** Navigation happens immediately — no "End session?" dialog appears
**Verify:** Try every navigation path during a session — zero dialogs. Compare with pre-P511 behavior.

## UAT-14: Auto-close timer communicates clearly
**Given:** Partner is seeing reconnecting countdown
**Then:** Countdown format is "M:SS remaining" (e.g., "1:45 remaining")
**Then:** Below 30 seconds, text changes color to orange (urgency signal)
**Then:** Timer uses tabular-nums (no layout jitter as digits change)
**Verify:** Watch countdown tick — smooth, no jumps, color changes at 30s.

## UAT-15: No zombie sessions
**Given:** Both partners have disconnected (both navigated away)
**When:** 2 minutes pass with no heartbeat from either
**Then:** Session is marked as ended
**Then:** Neither partner sees a rejoin prompt on next visit to /live
**Verify:** Both leave → wait 3 min → both visit /live → normal landing page. Check DB: session ended.

## UAT-16: Guest display name restored on rejoin
**Given:** Guest (unverified user) entered "Alex" as display name and joined a session
**When:** Guest navigates away and returns to /live within grace period
**Then:** Rejoin prompt shows "Rejoin as Alex" — no need to re-enter name
**Verify:** Guest joins with name → navigates away → returns → name shown in prompt.

## UAT-17: Cannot create new session while active session exists
**Given:** User has an active session (as creator or joiner)
**When:** User navigates to /live
**Then:** Rejoin prompt shown instead of Create/Join landing
**Then:** "End Session" link available to end existing session first
**Then:** After ending, normal Create/Join landing appears
**Verify:** Active session → visit /live → see rejoin prompt, not create form.
