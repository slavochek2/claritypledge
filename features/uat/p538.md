# UAT: P538 — Agreement Download Image & Share Dropdown

## UAT-1: Download Image (active agreement, party)

### UAT-1.1: Download button visible on active agreement
**Given:** Authenticated user who is creator or partner of an active agreement
**When:** User navigates to `/agreements/{id}`
**Then:** "Download Image" button is visible above the certificate
**Verify:** Playwright — `getByRole('button', { name: /download image/i })`

### UAT-1.2: Download produces PNG
**Given:** Active agreement page with toolbar visible
**When:** User clicks "Download Image"
**Then:** Browser downloads a PNG file named `clarity-agreement-{displayId}.png`
**Verify:** Manual — check Downloads folder for correct filename and content (both names, terms, gold seal)

### UAT-1.3: Exported image includes both parties and terms
**Given:** Active agreement between "Alice" and "Bob" with custom terms
**When:** User downloads the certificate image
**Then:** PNG shows both names, "Active since" date, terms text, gold seal, QR code
**Verify:** Manual — open downloaded PNG, visually inspect

## UAT-2: Share Dropdown (active agreement, party)

### UAT-2.1: Share dropdown opens with all options
**Given:** Active agreement page with toolbar visible
**When:** User clicks "Share" button
**Then:** Dropdown shows: Copy Link, Share on LinkedIn, Invite by Email
**Verify:** Playwright — click Share, check dropdown items

### UAT-2.2: Copy Link copies agreement URL
**Given:** Share dropdown is open
**When:** User clicks "Copy Link"
**Then:** Agreement URL is copied to clipboard, toast shows "Link copied!"
**Verify:** Manual — paste clipboard, verify URL matches `/agreements/{id}`

### UAT-2.3: LinkedIn share guide opens
**Given:** Share dropdown is open
**When:** User clicks "Share on LinkedIn"
**Then:** Modal appears with 3 steps: Download certificate, Copy text, Open LinkedIn
**Then:** Share text references both party names and the agreement URL
**Verify:** Manual — read modal content, verify bilateral language

### UAT-2.4: Email invite opens mailto
**Given:** Share dropdown is open
**When:** User clicks "Invite by Email"
**Then:** Default mail client opens with pre-filled subject and body
**Then:** Body references both parties and agreement URL
**Verify:** Manual — check mailto content in email client

## UAT-3: Visibility rules

### UAT-3.1: Toolbar hidden on pending agreement
**Given:** Authenticated creator of a pending agreement
**When:** User navigates to `/agreements/{id}`
**Then:** Certificate is visible but no Download/Share toolbar
**Verify:** Playwright — `not.toBeVisible()` for both buttons

### UAT-3.2: Toolbar hidden on terminated agreement
**Given:** Authenticated party of a terminated agreement
**When:** User navigates to `/agreements/{id}`
**Then:** Muted certificate is visible but no Download/Share toolbar
**Verify:** Playwright — `not.toBeVisible()` for both buttons

### UAT-3.3: Toolbar hidden for non-party visitor
**Given:** Authenticated user who is NOT a party to a public active agreement
**When:** User navigates to `/agreements/{id}`
**Then:** Certificate is visible but no Download/Share toolbar
**Verify:** Playwright — `not.toBeVisible()` for both buttons
