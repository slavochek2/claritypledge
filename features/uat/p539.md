# P539 — Calibration Zero-State Redesign UAT

## UAT-1: Own profile — zero sessions

**Given:** Logged-in user with 0 completed verification sessions
**When:** User navigates to their own profile
**Then:**
- [ ] Ear icon + "Understanding Calibration" header displays
- [ ] 5 empty outlined dots visible (no filled dots)
- [ ] Text reads "5 sessions for calibration"
- [ ] No calibration bar or center marker visible
- [ ] Tooltip on hover/tap shows explanation text
**Verify:** Visual inspection on profile page

## UAT-2: Own profile — partial progress (2 sessions)

**Given:** Logged-in user with 2 completed verification sessions
**When:** User navigates to their own profile
**Then:**
- [ ] 2 filled blue dots + 3 empty outlined dots
- [ ] Text reads "3 more for calibration"
- [ ] Filled dots use blue color matching the calibration bar dot
**Verify:** Visual inspection on profile page

## UAT-3: Own profile — singular text (4 sessions)

**Given:** Logged-in user with 4 completed verification sessions
**When:** User navigates to their own profile
**Then:**
- [ ] 4 filled blue dots + 1 empty outlined dot
- [ ] Text reads "1 more for calibration" (singular — no "sessions" prefix)
**Verify:** Visual inspection on profile page

## UAT-4: Own profile — calibrated (≥5 sessions)

**Given:** Logged-in user with sufficient calibration data (status !== insufficient)
**When:** User navigates to their own profile
**Then:**
- [ ] Existing calibration bar with blue dot renders (no visual regression)
- [ ] No dots or progress text visible
- [ ] Tooltip shows calibration gap details as before
**Verify:** Visual inspection on profile page

## UAT-5: Guest profile — uncalibrated

**Given:** Visitor viewing another user's profile who has < 5 sessions
**When:** Visitor navigates to the user's profile
**Then:**
- [ ] Text reads "Not yet calibrated"
- [ ] No dots visible (no progress indicator)
- [ ] No calibration bar visible
**Verify:** Open profile in incognito or as different user

## UAT-6: Guest profile — calibrated

**Given:** Visitor viewing another user's profile who has calibration data
**When:** Visitor navigates to the user's profile
**Then:**
- [ ] Existing calibration bar with blue dot renders (same as own profile calibrated state)
- [ ] No "Not yet calibrated" text
**Verify:** Open profile in incognito or as different user

## UAT-7: Mobile layout

**Given:** Mobile viewport (320px width)
**When:** Viewing own profile with partial progress
**Then:**
- [ ] Dots + text fit on single line without wrapping
- [ ] Touch target for tooltip is usable (≥ 40px)
**Verify:** Chrome DevTools mobile simulation or real device

## UAT-8: Transition boundary

**Given:** User completes their 5th verification session
**When:** User returns to their profile page
**Then:**
- [ ] Dots disappear, calibration bar with blue dot appears
- [ ] Clean swap — no animation artifacts
**Verify:** Complete a session in /live, navigate to profile
