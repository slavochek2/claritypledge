# UAT: P584 — UnderstoodBadge shared component

## UAT-1: Feed card badge

### UAT-1.1: Zero count shows badge with ear icon
**Given:** A story with `understood_count = 0` in the feed
**When:** User views `/feed?tab=stories`
**Then:** Badge shows "👂 0 understood" (ear icon + text)
**Verify:** Playwright E2E — `p584-understood-badge.spec.ts`

### UAT-1.2: Positive count shows badge with ear icon
**Given:** A story with `understood_count = 3` in the feed
**When:** User views `/feed?tab=stories`
**Then:** Badge shows "👂 3 understood"
**Verify:** Playwright E2E

### UAT-1.3: Tooltip appears on hover
**Given:** Any story badge in the feed
**When:** User hovers over the badge
**Then:** Tooltip explains the metric ("No one has verified understanding..." or "N people verified...")
**Verify:** Playwright E2E + visual check

## UAT-2: Profile stories tab

### UAT-2.1: Badge with ear icon on profile stories
**Given:** Author's profile with stories
**When:** User views `/p/{slug}` → Stories tab
**Then:** Each story shows "👂 N understood" badge with tooltip
**Verify:** Playwright E2E

## UAT-3: Story detail page

### UAT-3.1: Badge with ear icon on story detail
**Given:** Any story detail page
**When:** User views `/story/{id}`
**Then:** Badge shows "👂 N understood" with tooltip
**Verify:** Playwright E2E

## UAT-4: Consistency

### UAT-4.1: Visual consistency across surfaces
**Given:** Same story visible on feed, profile, and detail
**When:** User compares badge appearance across surfaces
**Then:** Same ear icon, same "N understood" label, same tooltip pattern. Only text size may vary (xs on feed, sm elsewhere).
**Verify:** Visual comparison (Claude in Chrome)

### UAT-4.2: No old pill markup remains
**Given:** Codebase after P584
**When:** Grep for old pill patterns (`bg-gray-100 rounded-full.*understood`, `text-gray-600.*understood`)
**Then:** Zero matches — all replaced by `<UnderstoodBadge>`
**Verify:** `grep -r "bg-gray-100.*understood" src/` returns empty

## UAT-5: Live content cards

### UAT-5.1: Badge in live session story picker
**Given:** A `/live` session with linked stories
**When:** User sees story cards in the session
**Then:** Badge shows "👂 N understood" inline with points count
**Verify:** Manual (requires active `/live` session)
