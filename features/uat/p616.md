# UAT: P616 — Unlink Point from Story

> Auto-generated by /generate-tests — edit freely.

## Scenarios

### UAT-1: Unlink button visible to author only (AC-4)

**Given** a story with linked points viewed by the story author
**When** the story detail page loads
**Then** each QuotedPoint card shows the unlink button (Unlink2 icon) right-aligned below the card
**And** the button has tooltip text "Unlink point from story"
**And** the button is keyboard-focusable (reachable via Tab, activates on Enter/Space)

### UAT-2: Unlink button hidden from non-author (AC-4)

**Given** a story with linked points viewed by an authenticated non-author
**When** the story detail page loads
**Then** no unlink button is rendered on any QuotedPoint card

### UAT-3: Unlink button hidden from anonymous visitor (AC-4)

**Given** a story with linked points viewed by an unauthenticated visitor
**When** the story detail page loads
**Then** no unlink button is rendered on any QuotedPoint card

### UAT-4: Confirmation dialog shows point preview (AC-5)

**Given** the story author taps the unlink button on a point
**When** the confirmation dialog opens
**Then** the dialog title reads "Unlink point from story?"
**And** the point statement is shown (truncated to 80 characters if needed)
**And** the body reads "The point will remain visible to others who have taken positions on it."
**And** the dialog has Cancel and Unlink buttons
**And** the Unlink button uses destructive variant styling

### UAT-5: Confirm unlink removes point from story (AC-6)

**Given** the author confirms the unlink in the dialog
**When** `unlinkPointFromStory` resolves successfully
**Then** the point disappears from the story detail page point list
**And** a toast reads "Point unlinked from story."
**And** the story itself is not deleted

### UAT-6: Cancel unlink preserves the point (AC-5)

**Given** the author clicks Cancel in the unlink dialog
**When** the dialog closes
**Then** the point remains visible in the story's point list
**And** no toast appears

### UAT-7: Error handling on unlink failure (AC-7)

**Given** the author confirms the unlink
**When** `unlinkPointFromStory` returns `false` (failure)
**Then** a toast error reads "Failed to unlink point. Please try again."
**And** the dialog closes
**And** the point remains in the list

### UAT-8: Point survives unlink (AC-8)

**Given** a point has been unlinked from a story
**When** the user navigates to the point detail page
**Then** the point still exists with all its positions intact

### UAT-9: Last point unlinked from story (edge case)

**Given** a story has exactly one linked point
**When** the author unlinks that point
**Then** the story shows zero points with the existing empty-points UI
**And** the story itself is not deleted

### UAT-10: Loading state during unlink (edge case)

**Given** the author clicks Unlink in the dialog
**When** the request is in progress
**Then** the confirm button shows "Unlinking..." text
**And** the button is disabled (prevents double-submit)
