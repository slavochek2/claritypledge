# UAT: P621 — Unlink Point from Story on Point Detail Page

> Auto-generated by /generate-tests — edit freely.
> Surface: `/point/:id` only. Story author's expanded story card shows unlink icon in stats row.

## Scenarios

### UAT-1: Unlink button visible to story author (point detail)

**Given** a point detail page where the viewer has a linked story
**When** the viewer expands their story via the "1 story" pill
**Then** the story card stats row shows the unlink icon (Unlink2) next to the share button
**And** the button has tooltip text "Unlink point from story"
**And** the button is keyboard-focusable (reachable via Tab, activates on Enter/Space)

### UAT-2: Unlink button hidden from non-author (point detail)

**Given** a point detail page where another user has a linked story
**When** a non-author viewer expands that user's story
**Then** no unlink button appears in the story card stats row

### UAT-3: Unlink button hidden from anonymous visitor

**Given** a point detail page with position holders who have stories
**When** an unauthenticated visitor views the page
**Then** no unlink button appears on any expanded story card

### UAT-4: Confirmation dialog shows point preview

**Given** the story author taps the unlink icon on point detail
**When** the confirmation dialog opens
**Then** the dialog title reads "Unlink point from story?"
**And** the point statement is shown (truncated to 80 chars if needed)
**And** the body reads "The point will remain visible to others who have taken positions on it."
**And** the dialog has Cancel and Unlink buttons
**And** the Unlink button uses destructive variant styling (red)

### UAT-5: Confirm unlink removes story from expanded region

**Given** the author confirms the unlink in the dialog
**When** `unlinkPointFromStory` resolves successfully
**Then** the story card disappears from the expanded region
**And** the "1 story" pill disappears from the position row
**And** a success toast appears

### UAT-6: Cancel unlink preserves the story

**Given** the author clicks Cancel in the unlink dialog
**When** the dialog closes
**Then** the story card remains visible in the expanded region
**And** no toast appears

### UAT-7: Error handling on unlink failure

**Given** the author confirms the unlink
**When** `unlinkPointFromStory` returns false (failure)
**Then** a toast error reads "Failed to unlink point. Please try again."
**And** the dialog closes
**And** the story card remains visible

### UAT-8: Point and position survive unlink

**Given** a story has been unlinked from a point via point detail
**When** the page is reloaded
**Then** the point still exists with its statement
**And** the author's position is still visible in the position list
**And** only the story link is removed

### UAT-9: Loading state during unlink

**Given** the author clicks Unlink in the dialog
**When** the request is in progress
**Then** the confirm button shows "Unlinking..." text with spinner
**And** the button is disabled (prevents double-submit)
