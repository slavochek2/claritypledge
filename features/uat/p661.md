# P661 UAT: Letter Composition — Sender Walks Receiver's Reading Flow

## UAT-1: Receiver Setup Modal

### UAT-1.1: Modal opens from doc page
**Given:** Sender is on their doc page with 2+ stories
**When:** Sender clicks "Prepare a Letter"
**Then:** Modal opens with "Who is your letter for?" heading
**Verify:** Playwright — click button, assert modal visible

### UAT-1.2: Mode selector in modal
**Given:** Receiver setup modal is open
**When:** Sender views the modal
**Then:** Two options visible: "Specific people" and "Anyone with a link"
**Verify:** Playwright — assert both mode options present

### UAT-1.3: Private doc restricts mode
**Given:** Sender is on a PRIVATE doc page
**When:** Sender opens "Prepare a Letter" modal
**Then:** "Anyone with a link" option is disabled
**Verify:** Playwright — create private doc, check disabled state

### UAT-1.4: Email input appears for 1-to-1
**Given:** Modal is open
**When:** Sender selects "Specific people"
**Then:** Email input field appears
**Verify:** Playwright — click mode, assert input visible

---

## UAT-2: Prediction Walk

### UAT-2.1: Story-by-story display
**Given:** Sender completed receiver setup
**When:** Prediction walk begins
**Then:** Full-screen view shows story 1 of N with progress bar, LiveStoryCardExpanded with points visible, and prediction prompt
**Verify:** Visual QA — screenshot, check card layout matches /live

### UAT-2.2: Prediction prompt text
**Given:** Sender is on prediction walk, receiver is "Alex"
**When:** Story card is displayed
**Then:** Prompt reads "How well do you believe Alex understands your story?"
**Verify:** Playwright — assert text contains receiver name + "understands your story"

### UAT-2.3: Rating input
**Given:** Prediction walk shows a story
**When:** Sender looks at the rating input
**Then:** RatingButtons (0-10 discrete dots) are visible and interactive
**Verify:** Playwright — click rating, assert selection state

### UAT-2.4: Sequential progression
**Given:** Sender rated story 1
**When:** Sender clicks "Next Story"
**Then:** Story 2 appears, progress bar advances, story 1 no longer visible
**Verify:** Playwright — assert story count advances

### UAT-2.5: Points visible in read-only mode
**Given:** Story has linked points
**When:** Story card renders in prediction walk
**Then:** Points are expanded (visible), position buttons are hidden (read-only)
**Verify:** Visual QA — screenshot, check no position buttons shown

---

## UAT-3: Review + Send

### UAT-3.1: Review screen after last story
**Given:** Sender rated all stories
**When:** Last story's "Next" is clicked
**Then:** Review screen shows: receiver name, story count, per-story prediction values
**Verify:** Playwright — assert prediction values match what was set

### UAT-3.2: Preview link
**Given:** Review screen is visible
**When:** Sender sees the review screen
**Then:** "Preview as [Name]" link is present
**Verify:** Playwright — assert link visible, href contains `/preview`

### UAT-3.3: Seal & Send
**Given:** Review screen is visible
**When:** Sender clicks "Seal & Send"
**Then:** Letter is created (DB rows: clarity_letters, letter_deliveries, letter_predictions), confirmation screen shows "Letter Sealed"
**Verify:** Playwright — click seal, assert confirmation text. DB check: letter exists with status=sealed.

### UAT-3.4: Back to Doc from confirmation
**Given:** Confirmation screen visible
**When:** Sender clicks "Back to Doc"
**Then:** Navigates back to the doc detail page
**Verify:** Playwright — assert URL contains `/d/`

---

## UAT-4: Preview Route

### UAT-4.1: Preview renders receiver experience
**Given:** Sender has a doc with stories
**When:** Sender navigates to `/letter/:docId/preview`
**Then:** Stories render in reading flow format with preview banner: "THIS IS A PREVIEW"
**Verify:** Visual QA — compare preview layout to actual reading flow

### UAT-4.2: Preview ratings don't persist
**Given:** Sender is on preview page
**When:** Sender interacts with rating dots
**Then:** Dots are clickable but no `story_verifications` row is created in DB
**Verify:** Playwright — click rating, query DB, assert zero new rows

## UAT-5: Multi-Receiver (1-to-1)

### UAT-5.1: Sequential prediction walks
**Given:** Sender entered two receivers (Alex, Bob)
**When:** Prediction walk begins
**Then:** Walks through all stories for Alex first, then resets and walks for Bob. Prompt shows correct name each time.
**Verify:** Manual — send to 2 receivers, check both get individual predictions
