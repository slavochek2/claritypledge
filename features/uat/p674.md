# P674: Simplify /live — UAT Scenarios

## UAT-1: Single Linear Flow — Full Round

### UAT-1.1: Idle screen shows speak button (no mode toggle)
**Given:** Two participants in a /live session, idle state
**When:** Both see the idle screen
**Then:** A single "Speak" (or equivalent) button is visible; no Guided/Open mode toggle exists
**Verify:** E2E — `e2e/p674-smoke.spec.ts` (no mode toggle), visual QA via Playwright MCP

### UAT-1.2: Speaker initiates round → both enter sealed-bid rating
**Given:** Two participants on idle screen
**When:** Speaker taps "Speak" or selects a story
**Then:** Both participants see sealed-bid rating input simultaneously; each sees their role-appropriate question
**Verify:** E2E — `e2e/p674-linear-flow.spec.ts` (full round test)

### UAT-1.3: Both submit sealed bids → reveal shows gap
**Given:** Both in rating phase
**When:** Both submit their sealed-bid ratings
**Then:** Reveal screen shows both ratings and the gap between them
**Verify:** E2E — `e2e/p674-linear-flow.spec.ts`

### UAT-1.4: Paraphrase → listener explains back → speaker re-rates
**Given:** Reveal phase complete
**When:** Listener taps "Explain back", explains outside app, taps "I'm done"
**Then:** Speaker sees re-rating prompt; submits post-paraphrase rating (#3)
**Verify:** E2E via advanceSessionState

### UAT-1.5: Sliders → 10/10 convergence → celebration
**Given:** Paraphrase complete, both in slider phase
**When:** Both move sliders to 10/10 and hold for 2 seconds
**Then:** Celebration screen appears for both; both acknowledge → returns to idle
**Verify:** E2E — `e2e/p674-linear-flow.spec.ts`

## UAT-3: Race Conditions (P671 Fix)

### UAT-3.1: Simultaneous rating submission
**Given:** Both in rating phase
**When:** Both submit within <100ms of each other
**Then:** Both ratings are preserved; neither is lost to a write collision
**Verify:** E2E — `e2e/p674-linear-flow.spec.ts` (race condition section)

### UAT-3.2: Stale Realtime echo after submission (P671 scenario)
**Given:** Creator submits rating, moves to waiting phase
**When:** A stale Realtime echo arrives with ratingASubmitted: false
**Then:** The monotonic guard rejects the stale echo; ratingASubmitted remains true
**Verify:** Unit — `src/tests/live-state-guard.test.ts`; E2E — `e2e/p674-linear-flow.spec.ts`

### UAT-3.3: Simultaneous celebration acknowledgment
**Given:** Both on celebration screen
**When:** Both tap "Continue" within <100ms
**Then:** Both acks persist; session transitions to idle
**Verify:** E2E — `e2e/p674-linear-flow.spec.ts`

### UAT-3.4: Partner disconnect during reveal
**Given:** Both on reveal screen
**When:** One participant's browser disconnects
**Then:** Other participant sees departure notice within grace period
**Verify:** E2E — `e2e/p674-linear-flow.spec.ts`
