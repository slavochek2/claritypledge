## UAT-2: Superseded Point Detail — Banner + Jump Link

**Purpose:** A user who lands on a superseded point's detail page must see a clear banner with a working link to the current head.

### UAT-2.1: Banner visible on superseded point

**When:** User navigates directly to `/point/{v1-point-id}`
**Then:** A banner reading "Superseded by" (or equivalent) is prominently visible above the point statement

### UAT-2.2: Jump link navigates to head

**Given:** Banner is visible on a superseded point
**When:** User clicks the link in the banner
**Then:** Browser navigates to the current head of the chain (the most recent non-superseded version), even if the chain has depth > 1
**Verify:** Manual — click the banner link, confirm URL changes to the head point's `/point/{headId}` URL and the page loads correctly

### UAT-2.3: Direct URL resolves without 404

**Given:** A superseded point exists in the DB
**When:** User navigates directly to `/point/{superseded-point-id}` via URL
**Then:** Page loads successfully (HTTP 200, no redirect, no 404/500 error) and banner is displayed
**Verify:** `e2e/p800-supersede-banner.spec.ts` — tests 3–4; manual URL navigation

## UAT-7: Trigger Rejects Invalid Supersede (SQL — Founder Runs)

**Purpose:** Database-level invariants protect against cross-variant supersede and cycles.

### UAT-7.1: Cross-variant supersede is rejected

**Given:** Point A (main variant, no `misunderstanding` in system_tags) and Point B (anti variant, `misunderstanding` in system_tags)
**When:** Founder attempts: `UPDATE points SET superseded_by = B.id WHERE id = A.id`
**Then:** The statement fails with an error (trigger rejects it)
**Verify:** `e2e/integration/p800-supersede-migration.spec.ts` — tests 4–5; manual SQL on test DB

### UAT-7.2: Cycle attempt is rejected

**Given:** Chain A → B (A.superseded_by = B.id)
**When:** Founder attempts: `UPDATE points SET superseded_by = A.id WHERE id = B.id`
**Then:** The statement fails with an error (trigger detects cycle)
**Verify:** `e2e/integration/p800-supersede-migration.spec.ts` — test 7; manual SQL on test DB

### UAT-7.3: Target-not-head is rejected

**Given:** Chain A → B → C (B.superseded_by = C.id)
**When:** Founder attempts: `UPDATE points SET superseded_by = B.id WHERE id = D.id` (B is not the head — C is)
**Then:** The statement fails with an error (trigger rejects non-head target)
**Verify:** `e2e/integration/p800-supersede-migration.spec.ts` — test 6; manual SQL on test DB
