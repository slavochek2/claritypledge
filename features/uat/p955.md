## Scenario A — Gate BLOCKS a commit containing the P952 defect

**Given:** A staged change that introduces two full-width primary buttons in the same view (the P952 pattern — use `src/tests/p955-fixture.tsx` as the staged file, or a temporary component that imports it).

**When:** `git commit` is run (without `--no-verify`).

**Then:**
- `pre-commit-checks.sh` runs the UI gate block.
- `npx vitest run src/tests/p955-gate.test.ts` exits non-zero.
- The commit is BLOCKED with a message identifying `P955-gate [one-primary]` and `P955-gate [no-dead-disabled]`.
- The terminal shows the per-defect failure message (not a generic gate failure).

**Verification:** Run `echo $?` immediately after the blocked commit — must be non-zero. Read the terminal output; it must name both defects.

- **Also confirm real 320px overflow + 44px touch targets** here using the `/tree/_gate/*` harness + a manual browser at 320px (the jsdom checks cover the structural case; real layout is confirmed here).

**Verification:** Read terminal output. Confirm `chrome-unavailable: deferred` appears and the commit result matches the deterministic results, not Chrome availability.

## Scenario F — Override is non-overridable when `.tsx` files are in the diff (spec 2f)

**Given:** `.ui-gate-override` exists with a valid future expiry (`echo 'expires: 2099-01-01' > .ui-gate-override`). A staged diff includes a `.tsx` file. A gate-failing fixture is staged.

**When:** `git commit` is run.

**Then:**
- The hook reads `.ui-gate-override` and finds a valid expiry.
- BUT `.tsx` files are in the diff → override is IGNORED, gate fires.
- Commit is BLOCKED regardless of the override file.
- Terminal shows: `UI gate override IGNORED — .tsx files in diff.`

**Verification:** Confirm the commit was blocked. Clean up: `rm .ui-gate-override`. Then stage a `.ts`-only change (no `.tsx`) and confirm the override IS respected.

**Also verify self-grant refusal:** Ask the agent to create `.ui-gate-override`. It must decline and instruct the founder to create it manually.
