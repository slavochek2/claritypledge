# RLS drift allowlist (P1048) — read by scripts/rls-drift-check.py
#
# Format:  direction|table|policyname      # reason, dated
# Directions: prod-only | not-in-files | unconditional-write | test-only | differs
#
# prod-only, not-in-files and unconditional-write gate the exit code. test-only
# and differs are reported for review and never fail the check, so they rarely
# need an entry.
#
# RULES FOR ADDING AN ENTRY
#   1. Every entry needs a reason on the line and a date. No bare entries.
#   2. An entry says "this difference is EXPECTED", never "we haven't got to it
#      yet". A backlog item belongs in features/, not here — suppressing it here
#      makes the check report clean while prod is not.
#   3. prod-only is almost never legitimate. Test-only dev-support policies are.
#      If you are about to allowlist a prod-only entry, that is the moment to
#      stop and ask why prod has something test does not.
#
# The check being red is the check working. P1046 is what a green-by-suppression
# check costs: four permissive policies sat live on prod, one of them exposing
# private data through an unauthenticated read.

# --- 2026-08-12, first run ---------------------------------------------------
